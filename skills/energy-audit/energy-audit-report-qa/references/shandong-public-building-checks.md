# 山东公共建筑报告校验清单

适用：`base.unit_type=公共建筑` 且 `base.province=山东`。

## 阻断项（P0）

| 编号 | 检查 | 判据 |
|---|---|---|
| S1 | 章节 | 第1～8章齐备 |
| S2 | 第2章 | 必须为“建筑概况”，不得写成“公共机构概况” |
| S3 | 子类 | 只允许机关办公、商务办公、宾馆酒店、医院，且必须由平台 `customer_func/children_func` 解析 |
| S4 | 标准 | `A1/A2/A3`→5076-2024；`B`→5077-2016；`C`→5078-2024；`D1～D4`→5079-2024 |
| S5 | 指标 | eA 单位建筑面积供暖能耗、eB 单位建筑面积非供暖电耗；机关办公另查含供暖总等效电耗，医院另查 eC |
| S6 | 档位 | 只有约束值、先进值两项；不得出现基准值、引导值 |
| S7 | 跨族 | 不得出现 DB33、736、760 或公共机构旧等价值 0.31 |

## 5077 过渡例外

- DB37/T 5077-2016 已于 2024-10-09 废止，仅允许山东公共建筑 `B=机关办公`。
- 报告必须逐字写明：
  “DB37/T 5077-2016标准已于2024-10-09废止；本项目因暂无现行替代标准，按批准规则作过渡兼容沿用。”
- DataVA 对合规过渡记 P2 风险提示，不阻断。
- 缺少上述固定披露、用于其他地区或其他子类，或混用 5076/5078/5079 均记 P0。

## 计算口径

- eA = 供暖能耗（kgce）÷ 供暖面积（m²）。
- eB = 非供暖等效电（kWh）÷ 面积；医院按 DB37/T 5079-2024 第6.0.4条采用医院建筑供暖面积。
- eC = 非供暖等效电（kWh）÷ 床位数 ÷ 1000，单位 `10³ kWh/(床·a)`。
- 机关办公总等效电耗 = （非供暖等效电 + 供暖等效电）÷ 建筑面积，单位 `kWh/(m²·a)`。
- 修正系数只作用于标准限额，不改写实测指标。
- 酒店缺星级、医院缺三级/二级及综合/专科属性时停止计算并补采。
