## 二、指标（P0）

| 编号 | 检查 | 判据 |
|---|---|---|
| I1 | 指标集 | 办公/场馆 5 项；公寓/饭店 2 项，且 5.3.1 必须是单位可比综合能耗、5.3.2 是单位床年用水量 |
| I2 | 电力系数 | 0.1229，不得出现 0.31 |
| I3 | 单位面积能耗 | 736：建筑能耗 ÷ 面积；可分项计量的特殊/食堂/浴室/健身应剔除；不扣供暖电量 |
| I4 | 单位面积电耗 | 总电量 ÷ 面积，不扣供暖电量 |
| I5 | 人均指标 | 分母为人数，不是面积 |
| I6 | 水耗 | 办公为 m³/(p·a)；公寓/饭店正式指标为 `Vuc = Vk ÷（N×Q）`，即年度用水量 ÷（总床位数×宾馆床位出租率），单位 m³/(床·年)；`Vk ÷ N` 仅作后台中间量 |
| I7 | 饭店修正 | 修正系数连乘后作除数；逐项列明，不只列出出租率 |
| I8 | 指标表 | 基础数据 → 指标 → 对标 → 评价，行序完整 |
| I9 | 结论句 | 与表内评价结果逐字一致 |
| I10 | 736 维度 | 行政机关按省级/市级/县级；场馆按科技馆/文化馆/博物馆；不得默认市级 |
| I11 | 736 剔除 | 可分项计量的特殊/食堂/浴室/健身已剔除；未分项计量有说明 |
| I12 | 736 修正 | 2005 年前且无中央空调的办公建筑，综合能耗/建筑能耗/电耗 ×1.2 |
| I13 | 760 档位 | 报告三行固定为定额标准约束值、基准值、引导值；对应标准原表 3级/2级/1级，但报告不得保留 1/2/3级旧名称；评价只用“低于引导值/低于基准值/低于约束值/高于约束值” |
| I14 | 760 新水 | 有水数据时，综合能耗含新水（市政自来水）0.2571 kgce/t；缺新水但电量完整的年度仍进入 5.3.1，新水量及新水折标量写“—”，正文说明评价反映已计量的电力部分；不得填 0，且不进入 5.3.2 |
| I15 | 760 面积 | Mm = 总建筑面积 − 30×地下车位数；人防不计入 |
| I16 | 760 参考项 | 常规电耗不是 760 指标，只能作额外参考，不得对标 736 |
| I17 | 760 中间量 | 单位综合能耗 Ej 只用于计算单位可比综合能耗；不得单列指标节、评价为“参考指标”或写入第8章指标结论 |
| I18 | 760 公式 | 5.3.1 用 OMML 写 `Ekd = Ej / (a1a2…am)`；式中按标准原文列示 `Ekd`、`Ej`、`a`、`m`，不得把 `a`、`m` 合并成“各项修正系数连乘值” |
| I19 | 床年用水公式 | 5.3.2 用 OMML 写 `Vuc = Vk / (N×Q)`；式中列示 `Vuc`、`Vk`、`N`、`Q`；不得退回 `Vk / N`，不得另列“按出租率折算的单位用水量” |
| I20 | 760 综合能耗表 | 表5.2 行序固定为“年耗电量→折标准煤系数（kgce/kWh）→年取水量→折标准煤系数（kgce/t）→综合能耗→建筑面积→单位综合能耗”；不得合并两个系数，表内不得出现评价结果；表5.3 才展示单位可比综合能耗、三档定额和评价结果 |
| I21 | 能源品种完整性 | 至少分别记录电量完整、用水完整和新水计量完整三个状态；电量完整但新水缺失时，应保留其用电总量、逐月趋势、电费、5.3.1 计算与评价，不得把缺失新水写成 0 |
