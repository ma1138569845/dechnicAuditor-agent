> 适用：8 章实务版
> 分级：P0 阻塞交付 / P1 交付前修复 / P2 提示

## 一、结构（P0）

| 编号 | 检查 | 判据 |
|---|---|---|
| S1 | 章数 | 1~8 章齐备 |
| S2 | 第2章章名 | **建筑概况**；不得出现"公共机构概况" |
| S3 | 第6章结构 | 6.1 用电 / 6.2 用水 / 6.3 其他 |

## 二、指标（P0）

| 编号 | 检查 | 判据 |
|---|---|---|
| I1 | 指标集 | 办公/场馆 5 项；公寓/饭店 3 项 |
| I2 | 电力系数 | 0.1229，不得出现 0.31 |
| I3 | 单位面积能耗 | 736：建筑能耗 ÷ 面积；可分项计量的特殊/食堂/浴室/健身应剔除；不扣供暖电量 |
| I4 | 单位面积电耗 | 总电量 ÷ 面积，不扣供暖电量 |
| I5 | 人均指标 | 分母为人数，不是面积 |
| I6 | 水耗 | 办公 m³/(p·a)；公寓 m³/(床·年)，按"定额×床位数×入住率"折算 |
| I7 | 饭店修正 | 修正系数连乘后作除数；逐项列明，不只列出出租率 |
| I8 | 指标表 | 基础数据 → 指标 → 对标 → 评价，行序完整 |
| I9 | 结论句 | 与表内评价结果逐字一致 |
| I10 | 736 维度 | 行政机关按省级/市级/县级；场馆按科技馆/文化馆/博物馆；不得默认市级 |
| I11 | 736 剔除 | 可分项计量的特殊/食堂/浴室/健身已剔除；未分项计量有说明 |
| I12 | 736 修正 | 2005 年前且无中央空调的办公建筑，综合能耗/建筑能耗/电耗 ×1.2 |
| I13 | 760 档位 | 3级（既有）/2级（新建改建）/1级（先进），不得写成约束/基准/引导 |
| I14 | 760 新水 | 综合能耗含新水 0.2571 kgce/t；未计入需说明理由 |
| I15 | 760 面积 | Mm = 总建筑面积 − 30×地下车位数；人防不计入 |
| I16 | 760 参考项 | 常规电耗不是 760 指标，只能作额外参考，不得对标 736 |

## 五、写作边界（P1）

| 编号 | 检查 | 判据 |
|---|---|---|
| W1 | 第5章结论 | 不写判词/建议/整改 |
| W2 | 第6章 | 不写改造建议；不编造型号/功率/运行时间；构成段不逐行复述设备清单表，完整明细留表中 |
