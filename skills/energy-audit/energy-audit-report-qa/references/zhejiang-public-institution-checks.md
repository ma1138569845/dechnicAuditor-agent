# 浙江公共机构报告校验清单

适用：`base.unit_type=公共机构` 且 `base.province=浙江`。

## 阻断项（P0）

| 编号 | 检查 | 判据 |
|---|---|---|
| S1 | 章节 | 第1～8章齐备 |
| S2 | 标准 | 行政机关/场馆 DB33/T 736-2021；普通高校 DB33/T 737-2021；二级及以上医院 DB33/T 738-2021 |
| S3 | 适用范围 | 一级医院、成人高校、自考高校、普通中小学不得套用本包 |
| S4 | 档位 | 约束值、基准值、引导值三档必须完整，评价文字与数值重算一致 |
| S5 | 电力系数 | 0.1229 kgce/kWh |
| S6 | 跨族 | 不得出现 DB37、山东公共建筑二档或公共机构旧等价值 0.31 |
| S7 | 指标边界 | 不得混入浙江公共建筑专属指标（单位可比综合能耗、酒店星级指标等） |

## 计算口径

- 行政机关、场馆、普通高校：单位建筑面积能耗、人均综合能耗为主指标；单位面积电耗、人均电耗、EEUE 为参考指标。
- 二级及以上医院：可比单位建筑面积能耗、人均综合能耗为主指标；常规用能系统单位面积电耗、EEUE 为参考指标。
- 738 可比单位面积能耗 = 单位面积能耗 ÷ `(α1 × α2)`；门急诊人次与开放床位触发修正时，必须在报告中披露。
- EEUE 没有数据中心总电量与 IT 设备电量分项时不计算、不虚构。
- 用水指标引用浙江省用（取）水定额（2019），只在有用水量时评价。
