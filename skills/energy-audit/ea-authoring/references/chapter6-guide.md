# 第6章：主要能源资源利用系统分析 — 生成指南

## 生成模式

**动态节数 + 设备表 + 照片**。`build_chapter6()` 根据 `chapter6` 中实际提供的数据自动生成对应小节，无数据的系统自动跳过。

## 核心原则

**有多少设备就写多少段，没有就跳过**。不要求补齐所有系统。

## 自动推断规则（v3.2）

**全自动数据驱动**：`build_chapter6()` 从 `chapter6._equipment` 和建筑数据自动推断，无需用户提供文本。

### 6.1 用电系统

**收集所有用电设备**（category in ['空调','照明','办公','热水器','厨房']），不仅空调。
多段描述：空调概况 + 照明概况 + 办公设备 + 其他。
**不要写【待补充】**。设备清单表包含所有用电设备（前15个）。

### 6.2 用水系统

固定模板："XX用水系统由市政自来水供给，主要用于生活用水、卫生清洁用水及空调系统补水等。"

### 6.3 供暖系统

从 `buildings[].heating_source` + `heating_terminal` 推断。
兜底：从 `energy_data.heating_energy_heat_gj > 0` 判断是否有供暖。
**无数据时返回 `None` 跳过该节，不显示【待补充】占位符。**

## Pitfalls

1. **6.1 取所有用电设备**: `all_elec = [e for e in _equipment if e.category in ('空调','照明','办公','热水器','厨房')]`，不仅取空调
2. **6.3 无数据时跳过不显示占位符**: `data = None` → `continue`

## 设备表格式

```
表6.N  XX系统设备清单
序号 | 设备名称 | 规格/功率 | 数量 | 备注
```

## 数据来源

完全依赖用户提供（数据库设备表当前为空）。照片由用户提供。

## 照片

每节至少1张现场设备照片。嵌入方式同前：`_add_image_with_caption`，宽12cm，图注10pt居中。
