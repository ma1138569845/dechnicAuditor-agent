# 第6章：主要能源资源利用系统分析 — 写作指南（权威）

> 2026-09-04 以烟台经开区法院正式报告第6章为基准逐段提炼。本文件是第6章写作的**总入口**；
> 6.1 分系统详规见 `chapter6-sub-system-spec.md`，6.5 详规见 `chapter6-indoor-env.md`。

## 章节结构（对齐正式报告）

```
第6章 主要能源资源利用系统分析
├── 6.1 用电系统运行分析（总述 + 分系统小节，见 chapter6-sub-system-spec.md）
├── 6.2 用水系统运行分析
├── 6.3 用热系统运行分析
├── 6.4 其他用能系统运行分析
└── 6.5 室内环境检测（见 chapter6-indoor-env.md）
```

## 核心原则

1. **有多少设备写多少段，没有就跳过**；无数据时写作中用 ⚠️ 提示向用户索取，**交付版不出现提示语/【待补充】占位**。
2. **每个分系统 = 叙述段 + 设备照片 + 设备清单表**（信息机房/变配电可只有叙述+照片，无表）。
3. **图/表编号跨小节连续**：图6.1、图6.2…表6.1、表6.2…按出现顺序递增；图注/表题在图表**上方**（图注格式：图X.Y  说明文字；表题格式：表X.Y  表名）。

## 6.1 用电系统（详见 chapter6-sub-system-spec.md）

- 总述：`{单位}用电系统主要包括{分系统1}，主要设备为{设备举例}；{分系统2}，主要设备为…等。`——**列系统名+主要设备名，不写数量数字**。
- 小节顺序：①空调与供暖 ②照明 ③办公设备 ④其他用电设备 ⑤信息机房 ⑥变配电 ⑦厨房（有则写）。

## 6.2 用水系统

**写作规律（一段 + 照片，无表）**：水源 → 供水系统及设备 → 用水分类逐层细分 → 特殊方式说明。

模板：
`{单位}用水为市政水，设有{供水系统}，配备{设备及数量}，用水包含{一级分类}。{一级分类}包含{二级细分}；{另一类}包含{细分}，{特殊说明如灌溉方式}。`

示例（正式版）："开发区法院用水为市政水，设有一套无负压供水系统，配备两台给水泵，用水包含生活用水、生态用水。生活用水包含饮用水与卫生用水；生态用水包含灌溉用水，主要为绿植灌溉，灌溉方式为喷灌。"

## 6.3 用热系统

**写作规律（一段，无表无图）**：热源类型 → 供暖期（依据地方供热管理办法 + 起止日期 + 当年按天气/政府规定调整说明）→ 缴费方式（按流量/按面积）→ 供暖单价 → 三年实际结算费用。

模板：
`{单位}冬季采用{热源}，采暖起止时间主要依据《{地方供热管理办法}》所规定供暖时间：{起止日期}；同时每年具体供暖时间依据当年天气及{单位}规定适当调整。{单位}使用{供热方式}，按{流量/面积}缴费，供暖缴费单价为{单价}元/GJ，{年份}年-{年份}年实际结算费用为{费用1}元、{费用2}元、{费用3}元。`

数据来源：`buildings[].heat_source`、`heat_time`（供暖期）、`metering.heat_pay_type`（按计量表/按面积）、`metering.heat_price`、`energy_yearly[].heating_cost_wan`（万元→元换算）。无数据跳过该节。

## 6.4 其他用能系统

**写作规律（过渡句 + 每种能源一段）**：过渡句点明除电/水/热外的能源品种，然后**每种能源一段：类型 + 车辆数（如有）+ 三年用量 + 三年费用**。

模板：
```
除用电、用水、用热的主要能源资源消耗外，{单位}还有公车用油和天然气消耗。

根据统计数据，{单位}公车用油为{油品}，{年份1}年至{年份3}年有公务用燃油车{辆}辆，{年份}年-{年份}年{油品}用量分别为{L1}L、{L2}L、{L3}L，{油品}费用分别为{费1}元、{费2}元、{费3}元。

根据统计数据，{单位}用气系统为天然气，{年份}年-{年份}年天然气用量分别为{m1}m³、{m2}m³、{m3}m³，燃气费用分别为{费1}元、{费2}元、{费3}元。
```

数据来源：`energy_yearly[].petrol_kg`（t→kg→L 换算按密度，或账单直接给 L）、`natural_gas_m3` 及对应 `*_cost_wan`。无数据跳过。

## 数据来源总表

| 内容 | 来源 |
|---|---|
| 设备清单 | `proj.equipment`（名称/类别/规格/数量/独立计量） |
| 冷热源/末端/供暖期 | `proj.buildings[]`（cold_source/heat_source/air_type/heat_type/heat_time 等） |
| 缴费方式/热价 | `proj.metering`（heat_pay_type/heat_price） |
| 三年用量/费用 | `proj.energy_yearly[]`（各能源字段 + *_cost_wan） |
| 车辆数/油品 | 账单或用户提供（DB 无则写作中提示索取） |
| 室内检测数据 | `proj.indoor_env` |
| 照片 | `proj.images`（分类：制冷设备/照明设备/办公设备/其他用电设备/信息机房/厨房设备，采集自设备分表 _img 列；每分系统一张拼图，多张照片带 (1)(2) 编号标题） |

## 照片规范

- 每个分系统 1 张拼图（多张现场照片拼为一张，各照片下带 (1)(2)…编号标题），宽 12cm，图注 10pt 居中。
- 嵌入用 office_editor；图注格式 `图X.Y  {单位简称}{系统}设备`（如"图6.1  开发区法院空调系统设备"）。
