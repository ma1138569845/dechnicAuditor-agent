## 第5章 能源资源消费/消耗指标分析

### 5.1 能源资源消费/消耗概况

**必备**：

- 一句话总述审计年份与数据基础；
- 能源类型清单（电/水/气/油）；
- 能源资源流向图（图5.1）。

**禁写**：

- 不列指标数值；
- 不写结论/评价；
- 不写建议。

### 5.2 能源资源消耗/消费数据

#### 5.2.1 用电情况分析

**四段结构**：

1. 设备列举 + 三年总电量；
2. 总电量趋势图（图5.2）+ 同比分析；
3. 逐月电量图（图5.3）+ 季节特征；
4. 高峰/异常归因。

**设备列举**：与第6章 6.1 一致（空调、照明、办公、特殊设备、变配电）。

**归因要求**：

- 制冷季/供暖季峰值：结合冷热源形式；
- 异常月份：结合入驻率、改造、疫情、漏水等现场事件；
- 无依据写"原因待核实"。

#### 5.2.2 用水情况分析

**四段结构**：

1. 用水构成 + 三年总水量；
2. 总水量趋势图（图5.4）；
3. 逐月水量图（图5.5）；
4. 异常说明（漏水、管线改造、接入调整）。

**规则**：

- 逐月为 0 或重复值必须说明；
- 估算/分摊值必须注明，不能当实测；
- 不按费用反推水量。

#### 5.2.3 其他用能分析

按实际写：

- 天然气（食堂/蒸汽）；
- 汽油（公务车）；
- 光伏（发电量/减排量）；
- 无则写"无其他化石能源消耗"。

#### 5.2.4 能源资源费用分析

**必备**：

1. 费用表（表5.1）；
2. 三年费用趋势；
3. 费用占比图（图5.6~5.8，每年一张）；
4. 结论句（哪类费用占比最高）。

**规则**：

- 费用单位统一"万元"，保留 2 位；
- 单价 = 费用 ÷ 用量，交叉校验；
- 费用与用量趋势不一致时解释（单价、漏水、分摊）。

#### 对标维度（必须先取数）

| 子类 | 维度 | 取值 |
|---|---|---|
| 行政机关 | 机构层级 | 省级 / 市级 / 县级及以下 |
| 场馆 | 场馆类型 | 科技馆 / 文化馆 / 博物馆 |
| 办公/场馆 | 食堂 | 有 / 无 |
| 办公/场馆 | 建筑投用年份 + 中央空调 | 2005 年前且无中央空调 → ×1.2 |
| 办公/场馆 | 特殊/食堂/浴室/健身 | 是否可分项计量 |
| 饭店 | 星级 | 五星 / 四星 / 三星及以下 |
| 饭店 | 建设性质 | 既有（3级）/ 新建改建（2级） |
| 饭店 | 修正项 | 洗衣房/泳池/热力管网/容积率/餐饮会议比/出租率 |

#### 736 口径要点

- 736 适用对象是行政机关、场馆；科研办公等非列举对象只能"参照"，并在 1.6/5.3 说明；
- 主要指标：单位建筑面积能耗、人均综合能耗；
- 参考指标：常规电耗、人均电耗、EEUE；
- 可分项计量的特殊用能、食堂、浴室、健身应剔除；没有分项计量则无法剔除，必须说明；
- 2005 年前投用且无中央空调的办公建筑，综合能耗/建筑能耗/电耗 ×1.2；
- 水耗按浙江省用水定额：有食堂 38/22.5，无食堂 21.9/15 m³/(p·a)。

#### 760 口径要点

- 760 适用对象是旅游饭店；专家公寓等公寓类只能"参照"，并说明"现行标准未设公寓专有指标"；
- 限额是 **3级（既有）/2级（新建改建）/1级（先进）**，不得写成"约束/基准/引导"；
- 综合能耗含新水 0.2571 kgce/t；
- 建筑面积 `Mm = 总建筑面积 − 30×地下车位数`；
- 单位可比综合能耗 = 单位综合能耗 ÷（修正系数连乘）；
- 水耗按 m³/(床·年)，并按"定额×床位数×入住率"折算；
- 样本的"常规电耗"不是 760 指标，只能作额外参考，不得对标 736。

#### 每项指标五要素

1. 定义（标准原文口径）；
2. 公式与符号说明；
3. 计算表（基础数据 → 指标 → 对标 → 评价）；
4. 结论句（数值 + 对标结果）；
5. 数据异常/不可比说明。

#### 结论句模板

> {建筑}{年份} {指标名}分别为{v1}{单位}、{v2}{单位}、{v3}{单位}，{均/其中}{高于/低于}{档位}{值}{单位}。

规则：

- 只写数值与对标结果；
- 不写判词（"节能空间/压力/短板"）；
- 不写建议/整改；
- 评价短语与表内"评价结果"逐字一致。

#### 数据不可比

出现以下情况时，在指标前说明"不予对标评价"：

- 只有半年/部分年份数据；
- 建筑刚投运/装修期；
- 水量只有 1 年；
- 计价/计量口径发生重大变化。

写法：

> {建筑}{年份}仅有{说明}，无法准确反映用能现状，本次审计不予对标评价。

## 第6章 主要能源资源利用系统分析

> 公共建筑族使用本结构，不套公共机构 R7 的 6.1.1~6.1.6。

### 6.1 用电系统运行分析

**固定顺序**：

1. 供暖空调系统；
2. 照明系统；
3. 办公设备；
4. 其他用电设备（科研/医疗/特殊）；

**每类写法**：

- 设备构成概述（设备类别、总数量、总装机容量、服务范围）；
- 运行方式（人工/集中控制/变频）；
- 现场问题（无铭牌、未更换、过度照明、车库无感应）。

品牌、型号、每类数量、单台功率和运行时间统一下沉设备清单表；正文不得逐行
复述表格。只有具体型号本身构成能效评价、淘汰落后或改造判断依据时，才在评价段
点出该型号。

## 第7章 节能效果与节能潜力分析

### 7.1 用能系统现状分析

**每条结构**：

```
7.1.N 问题名
现场事实/设备参数 → 影响（一句） → 依据（可选）
```

**问题来源只允许**：

- 设备台账（型号、能效、数量、运行时间）；
- 现场核查（控制方式、照明方式、保温、漏水）；
- 计量/统计数据（无分项、无独立计量）；
- 管理事实（无制度、无奖惩、无培训）。

**禁写**：

- 无现场事实的"随手关灯""加强管理"；
- 无来源的百分比（如"管理浪费占 5%~10%"）；
- 把第6章已写的设备描述原样重复。

### 7.2 节能潜力分析及建议

**每条与 7.1 一一对应**：

```
7.2.N 建议名
动作分解（一是/二是/三是） → 预计节能率/效益 → 投资/回收期（如有）
```

**常见五类**：

1. 多联机/空调集中控制；
2. 变压器能效提升；
3. 光伏/可再生能源；
4. 完善能耗监测系统；
5. 管理与行为节能。

**规则**：

- 节能率有依据才写，无依据写"需测算"；
- 光伏写容量、年发电量、减排量；
- 变压器写能效等级、更换型号建议；
- 管理类写"侧重于管理节能，节能量视应用深度而异"。

## 第8章 审计结论

**平铺式，不分节**：

1. 方法段；
2. 依据段（DB33 + 用水定额）；
3. 指标逐条评价（编号 1.…2.…）；
4. 原因分析（2~3 条）；
5. 建议清单（与 7.2.x 中除“节能率分析”外的各节对应，每条独立成段）。

**规则**：

- 指标值复用第5章，不引入新数；
- 评价短语与第5章逐字一致；
- 不写"公共机构"专属表述；
- 建议条数取 7.2.x 条数减“节能率分析”后所得数；
- 每条建议单独成段，不得用分号把多条建议挤在一段。
