## 第5章 能源资源消费/消耗指标分析

### 5.1 能源资源消费/消耗概况

**必备**：

- 一句话总述审计年份与数据基础；
- 能源类型清单（电/水/气/油）；
- 能源资源流向图（图5.1）。

**禁写**：

- 不列指标数值；
- 不写结论/评价；
- 不写建议。

### 5.2 能源资源消耗/消费数据

**年度完整性（P0）**：完整性按能源品种分别判断。某一年电量覆盖 12 个月且
年度总量完整时，必须纳入用电总量、逐月趋势、电费和附表分析；即使该年缺少
新水数据，也不得把完整电量一并排除出 5.3.1 单位综合能耗计算和评价。5.3.2
用水指标只使用水量完整的年度。缺项年度的缺失能源品种写“—”，正文说明评价
反映已计量的电力部分，但不得把缺失值写成 0 或补造数据。报告期本身不完整的
年度仍不进入 5.3 指标表，缺新水规则不得覆盖该独立排除条件。

#### 5.2.1 用电情况分析

**四段结构**：

1. 设备列举 + 各完整年度总电量；不完整年度仅作正文说明；
2. 总电量趋势图（图5.2）+ 同比分析；
3. 逐月电量图（图5.3）+ 季节特征；
4. 高峰/异常归因。

**设备列举**：与第6章 6.1 一致（空调、照明、办公、特殊设备、变配电）。

**归因要求**：

- 制冷季/供暖季峰值：结合冷热源形式；
- 异常月份：结合入驻率、改造、疫情、漏水等现场事件；
- 无依据写"原因待核实"。

#### 5.2.2 用水情况分析

**四段结构**：

1. 用水构成 + 各完整年度总水量；不完整年度仅作正文说明；
2. 总水量趋势图（图5.4）；
3. 逐月水量图（图5.5）；
4. 异常说明（漏水、管线改造、接入调整）。

**规则**：

- 逐月为 0 或重复值必须说明；
- 估算/分摊值必须注明，不能当实测；
- 不按费用反推水量。

#### 5.2.3 其他用能分析

按实际写：

- 天然气（食堂/蒸汽）；
- 汽油（公务车）；
- 光伏（发电量/减排量）；
- 无则写"无其他化石能源消耗"。

#### 5.2.4 能源资源费用分析

**必备**：

1. 费用表（表5.1，仅完整年度）；
2. 完整年度费用趋势；
3. 费用占比图（图5.6~5.8，每年一张）；
4. 结论句（哪类费用占比最高）。

**规则**：

- 费用单位统一"万元"，保留 2 位；
- 单价 = 费用 ÷ 用量，交叉校验；
- 费用与用量趋势不一致时解释（单价、漏水、分摊）。

#### 736 口径要点

- 736 适用对象是行政机关、场馆；科研办公等非列举对象只能"参照"，并在 1.6/5.3 说明；
- 主要指标：单位建筑面积能耗、人均综合能耗；
- 参考指标：常规电耗、人均电耗、EEUE；
- 可分项计量的特殊用能、食堂、浴室、健身应剔除；没有分项计量则无法剔除，必须说明；
- 2005 年前投用且无中央空调的办公建筑，综合能耗/建筑能耗/电耗 ×1.2；
- 水耗按浙江省用水定额：有食堂 38/22.5，无食堂 21.9/15 m³/(p·a)。

#### 760 口径要点

- 《旅游饭店单位综合能耗限额及计算方法》（DB33/T 760-2023）适用对象是
  旅游饭店；专家公寓等公寓类只能"参照"，并说明"现行标准未设公寓专有指标"；
- 报告表统一写 **定额标准约束值 / 定额标准基准值 / 定额标准引导值**；
  它们依次对应标准原表的 3级（限额值）/2级（约束值）/1级（先进值）；
- `12 kgce/m²` 是"三星级及以下"分项 1级（先进值）按报告口径映射后的
  引导值，不得写成"既有饭店定额标准引导值"；原表 25 kgce/m² 才对应
  3级既有饭店限额值；
- 评价沿用公共机构逻辑：`≤引导值` 为“低于引导值”，
  高于引导值且 `≤基准值` 为“低于基准值”，高于基准值且 `≤约束值` 为
  “低于约束值”，高于约束值为“高于约束值”；表格与结论逐字一致；
- 1/2/3级名称只用于标准溯源，不得出现在报告表格行名或评价结果中；
- 综合能耗含新水 0.2571 kgce/t；
- 5.3.1 的中间量表展示“单位综合能耗”：年耗电量、折标准煤系数
  （kgce/kWh）、年取水量、折标准煤系数（kgce/t）分别占行；不得把两个系数
  合并到一个单元格。表内不出现评价结果；
- 修正后的正式评价表展示“单位可比综合能耗”；单位综合能耗 Ej 只作为
  正式评价表的输入。缺新水但电量完整的年度仍进入 5.3.1，新水量及新水折标量
  写“—”，正文说明评价反映已计量的电力部分；不得按 0 折标；
- 同一段落或结论中不得只写“该标准表”“该定额”，首次引用必须写标准完整名称
  和标准号，例如“《旅游饭店单位综合能耗限额及计算方法》
  （DB33/T 760-2023）表1”；
- 建筑面积 `Mm = 总建筑面积 − 30×地下车位数`；
- 5.3.1 必须写公式 `Ekd = Ej / (a1a2…am)`，并逐项写标准“式中”：
  `Ekd` 为单位可比综合能耗，`Ej` 为单位综合能耗，`a` 为综合能耗修正系数，
  `m` 为第m项综合能耗修正系数；公式必须以 OMML 独占一段，不得压成纯文本；
- 修正系数采用连续乘积方式，连乘后作除数；
- 单位综合能耗 `Ej` 只是计算单位可比综合能耗的中间量，不得单列指标节、
  评价为“参考指标”或写入第8章指标结论；
- 水耗正式指标固定为 `Vuc = Vk / (N × Q)`，即
  `年度用水量 ÷（总床位数×宾馆床位出租率）`，单位为 m³/(床·年)；
  `Vk / N` 仅为后台中间量，不得作为报告指标、表格行或结论值；
- 5.3.2 用 OMML 写公式，并逐项列明 `Vuc`、`Vk`、`N`、`Q`；
  平台星级优先匹配
  H6110 旅游饭店：五星/四星 350/216，三星 256/146，一、二星级 180/110；
- H6120 一般旅馆—星级以下 125/70 只用于明确的一般旅馆/星级以下对象，
  不得因项目名称为“公寓”、用水较低或遗留字段为 `below` 而套用；
- 5.3.2 必须写明 H6110/H6120、类别和分项；平台星级与遗留
  `water_category` 冲突时，以平台星级为准；
- 样本的"常规电耗"不是 760 指标，只能作额外参考，不得对标 736。

#### 每项指标五要素

1. 定义（标准原文口径）；
2. 公式与符号说明；
3. 计算表（基础数据 → 指标 → 对标 → 评价）；
4. 结论句（数值 + 对标结果）；
5. 数据异常/不可比说明。

#### 结论句模板

> {建筑}{年份} {指标名}分别为{v1}{单位}、…、{vn}{单位}，{均/其中}{高于/低于}{档位}{值}{单位}。

规则：

- 只写数值与对标结果；
- 办公/场馆按 5 项正式指标列写；饭店只列单位可比综合能耗、单位床年用水量，
  不得把单位综合能耗 `Ej` 作为第三项；
- 不写判词（"节能空间/压力/短板"）；
- 不写建议/整改；
- 评价短语与表内"评价结果"逐字一致。

#### 数据不可比

出现以下情况时，在指标前说明"不予对标评价"：

- 只有半年/部分年份数据；
- 建筑刚投运/装修期；
- 水量只有 1 年；
- 计价/计量口径发生重大变化。

写法：

> {建筑}{年份}仅有{说明}，无法准确反映用能现状，本次审计不予对标评价。

## 第7章 节能效果与节能潜力分析

### 7.1 用能系统现状分析

**每条结构**：

```
7.1.N 问题名
现场事实/设备参数 → 影响（一句） → 依据（可选）
```

**问题来源只允许**：

- 设备台账（型号、能效、数量、运行时间）；
- 现场核查（控制方式、照明方式、保温、漏水）；
- 计量/统计数据（无分项、无独立计量）；
- 管理事实（无制度、无奖惩、无培训）。

**禁写**：

- 无现场事实的"随手关灯""加强管理"；
- 无来源的百分比（如"管理浪费占 5%~10%"）；
- 把第6章已写的设备描述原样重复。

### 7.2 节能潜力分析及建议

**每条与 7.1 一一对应**：

```
7.2.N 建议名
动作分解（一是/二是/三是） → 预计节能率/效益 → 投资/回收期（如有）
```

**常见五类**：

1. 多联机/空调集中控制；
2. 变压器能效提升；
3. 光伏/可再生能源；
4. 完善能耗监测系统；
5. 管理与行为节能。

**规则**：

- 节能率有依据才写，无依据写"需测算"；
- 光伏写容量、年发电量、减排量；
- 变压器写能效等级、更换型号建议；
- 管理类写"侧重于管理节能，节能量视应用深度而异"。

## 第8章 审计结论

**平铺式，不分节**：

1. 方法段；
2. 依据段（DB33 + 用水定额）；
3. 指标逐条评价（编号 1.…2.…）；
4. 原因分析（2~3 条）；
5. 建议清单（与 7.2.x 中除“节能率分析”外的各节对应，每条独立成段）。

**规则**：

- 指标值复用第5章，不引入新数；
- 评价短语与第5章逐字一致；
- 不写"公共机构"专属表述；
- 建议条数取 7.2.x 条数减“节能率分析”后所得数；
- 每条建议单独成段，不得用分号把多条建议挤在一段。
