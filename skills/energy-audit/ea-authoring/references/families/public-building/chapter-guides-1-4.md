## 第1章 能源审计执行概要

### 1.1 审计目的

**目的**：说明"为什么做、谁委托、审计谁"。

**结构（两段）**：

1. 公共建筑能源审计定义（固定表述）；
2. 委托关系 + 审计对象。

**固定表述**：

> 公共建筑能源审计是指依据有关法律、法规、规章和标准，对公共建筑的用能系统、设备的运行、管理及能源资源利用状况进行检验、核查和技术、经济分析评价，提出改进用能方式或提高用能效率建议和意见的行为。

**第二段模板**：

> 为了准确了解{单位}{建筑}的用能情况，{委托单位}委托{审计机构}对该建筑进行能源审计。

**数据来源**：项目基本信息、委托单位字段。

**禁写**：

- "公共机构能源审计是指……"；
- 无委托单位时编造委托关系（写"受……委托"或按项目实际）。

### 1.2 审计范围

**必备要素**：

1. 地址（省/市/区/路/号）；
2. 建筑名称；
3. 建筑面积（m²）；
4. 数据年份；
5. 分析指标清单；
6. 对标维度：行政机关层级 / 场馆类型 / 饭店星级与建设性质。

**模板**：

> 本次能源审计范围包含位于{地址}的{单位}{建筑}，建筑面积{面积}m²。
>
> 本次能源审计工作基于{起始年}—{结束年}整年及每月的电、水等能源账单及能耗统计数据，同时结合现场勘察所收集的建筑围护结构、各类用能设备资料、日常用能习惯等实际数据信息，对{建筑}年总能耗、单位建筑面积能耗、常规用能系统单位建筑面积电耗、人均综合能耗、人均电耗、单位用水量等进行分析计算，依据国家或地方能耗定额标准，对建筑用能现状进行总体评价。

**规则**：

- 公寓/饭店类删去"人均综合能耗、人均电耗"，改为"单位可比综合能耗、单位用水量"；
- 多栋项目逐栋列面积，或写"范围内共 N 栋，总建筑面积 X m²"；
- 建筑面积必须与第2章表2.1 一致。

### 1.3 审计周期

**两段式**（样本口径）：

```
审计时间：{YYYY年M月—YYYY年M月}
审计周期：{YYYY年1月1日—YYYY年12月31日}
```

**规则**：

- 不写"基准期"（样本没有）；
- 数据年份与 1.2 一致；
- 若某年只有部分数据，在 1.3 或 5.3 说明。

### 1.4 审计内容

**固定三段**：

1. 能源资源管理情况；
2. 能耗分析评价；
3. 节能潜力分析及建议。

**禁写**：把公共机构的"8 章内容"逐条罗列。

### 1.5 审计过程

**固定三段**：

1. 前期：调研表、资料收集、初步评估；
2. 中期：现场调研、数据核实、设备与系统确认；
3. 后期：数据汇总、用能分析、潜力挖掘、报告提交。

**规则**：可按项目实际情况补充，但不要写成"审计方法"清单。

### 1.6 审计依据

**分组排列**（每组用 ● 或分号）：

1. 国家法规与导则：
   - 节约能源法；
   - 公共建筑能源审计技术导则（2016）；
   - GB/T 2589 综合能耗计算通则；
   - GB 55015 建筑节能与可再生能源利用通用规范；
   - GB/T 29149 公共机构能源资源计量器具配备和管理要求；
   - 其他专业规范（电气、暖通、给排水、照明、室内空气）。
2. 浙江省规章：
   - 浙江省公共机构节约能源资源"十四五"规划；
   - 浙江省公共机构节约能源资源评价管理办法。
3. 定额标准：
   - DB33/T 736-2021（办公/场馆，按省级/市级/县级或科技馆/文化馆/博物馆取行）；
   - DB33/T 760-2023（公寓/饭店，按五星/四星/三星及以下、既有/新建改建取列）。
4. 用水定额：
   - 浙江省用（取）水定额（2019）。

**适用范围说明（必写）**：

- 736 的适用对象是行政机关、场馆；760 的适用对象是旅游饭店；
- 科研办公、专家公寓等非标准列举对象，只能写"**参照** DB33/T 736-2021 / DB33/T 760-2023"，并说明参照理由；
- 不得把"参照"写成"依据"，也不得伪装成标准直接适用对象。

**禁写**：

- DB37 系列；
- 山东地方供热办法；
- 未核验的标准编号/年份。

## 第2章 建筑概况

> 2026-10-20 用户确认：本章章名固定为"**建筑概况**"，不得使用"公共机构概况"。

### 2.1 基本情况

**内容**：

- 单位/园区背景与职能；
- 建筑功能定位（科研办公/公寓/场馆）；
- 本次审计对象与院区关系。

**规则**：

- 不写"公共机构"属性、编制、经费来源等公共机构专属信息；
- 单位简介控制在 2~3 段，不复制官网长文；
- 首段必须出现建筑全称。

### 2.2 建筑物概况

**必备表 2.1**：

`建筑名称 | 建筑面积（m²） | 建筑层数 | 建筑高度（m） | 投用年份 | 是否中央空调 | 空调冷源 | 末端形式 | 结构类型 | 保温材料`

**规则**：

- 单体报告：表2.1 可只列本次审计建筑；正文简述院区其他建筑；
- 园区汇总：表2.1 列全院区建筑，标注是否纳入本次审计；
- 面积保留 2 位小数（样本有 19,418.41）；
- **投用年份 + 是否中央空调**：用于判断 736 §6.3 的 1.2 修正（2005 年前且无中央空调）；
- 未知字段写"—"，不编造；
- 图2.1 单位/院区外观；图2.2 平面布置；图2.3 主体建筑照片。

### 2.3 能源资源利用情况

**按四类写**：

1. 用电系统：供暖空调、照明、办公、特殊用能、变配电；
2. 用水系统：生活用水、工艺用水、灌溉、空调补水；
3. 燃气系统：厨房炊具/蒸汽锅炉；
4. 用油系统：公务车。

**规则**：

- 设备名与第6章一致；
- 只写"有哪些系统"，不写运行评价；
- 没有的能源写"无"或省略。

## 第3章 能源资源管理状况

### 3.1 机构职责

**三层写法**：

1. 决策层：资产部/后勤/能源管理领导小组；
2. 执行层：服务中心/物业；
3. 监督层：财务/审计/考核。

**必备内容**：

- 谁负责抄表；
- 谁负责统计；
- 谁负责缴费/分摊；
- 谁负责设备维保。

**禁写**：只列部门名称、不写职责。

### 3.2 目标方针

**内容**：

- 节能目标/方针；
- 收费或结算机制（如有）；
- 能耗定额/考核（如有）。

**规则**：

- 有电费分摊/结算机制的，写清单价、分摊系数、盈亏（样本 AB 座表3.1）；
- 没有的写"未建立"；
- 不写与建筑无关的公共机构节能指标。

### 3.3 能源资源管理成效与问题

**结构**：

1. 成效（2~3 条，带事实）；
2. 问题（2~3 条，管理类）；
3. 过渡句（引向第7章）。

**问题范围**：

- 无专职/兼职能源管理员；
- 无节能奖惩制度；
- 无培训/宣传；
- 无在线分析/预警；
- 收费/分摊机制不科学。

**禁写**：设备能效、照明改造等设备问题（归第6/7章）。

## 第4章 能源资源计量及统计状况

### 4.1 计量体系

**固定条文**（GB/T 29149）：

- 一级：进出单位/建筑总表；
- 二级：按行政办公区、业务区、保障区、特殊功能区计量；
- 三级：主要用能系统/设备单独计量。

**规则**：可沿用固定文字，不按项目改写。

### 4.2 计量器具配备及管理

**必备内容**：

- 电表数量、水表数量；
- 覆盖层级（总表/建筑/楼层/分项）；
- 是否满足分户、分区、分系统；
- 器具安装位置与检定。

**规则**：

- 数量取项目台账；
- 缺哪一级写哪一级；
- 不写"全部满足"除非有依据。

### 4.3 能源资源统计情况

**必备内容**：

- 在线监测系统名称/功能；
- 抄表频率；
- 统计汇总流程；
- 数据保存/上报。

**规则**：无在线系统写"人工抄表"；有系统写系统名与覆盖范围。

### 4.4 能源资源统计成效及问题

**结构**：成效 + 问题。

**常见问题**：

- 人工分析滞后，漏水/异常未及时发现；
- 部分表计未接入在线系统；
- 分项计量不完整；
- 数据颗粒度不足（只有总表）。

**禁写**：与计量无关的设备问题。
