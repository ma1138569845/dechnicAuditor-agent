## 第1章 能源审计执行概要

### 1.1 审计目的

**目的**：说明"为什么做、谁委托、审计谁"。

**结构（两段）**：

1. 公共建筑能源审计定义（固定表述）；
2. 委托关系 + 审计对象。

**固定表述**：

> 公共建筑能源审计是指依据有关法律、法规、规章和标准，对公共建筑的用能系统、设备的运行、管理及能源资源利用状况进行检验、核查和技术、经济分析评价，提出改进用能方式或提高用能效率建议和意见的行为。

**第二段模板**：

> 为了准确了解{单位}{建筑}的用能情况，{委托单位}委托{审计机构}对该建筑进行能源审计。

**数据来源**：项目基本信息、委托单位字段。

**禁写**：

- "公共机构能源审计是指……"；
- 无委托单位时编造委托关系（写"受……委托"或按项目实际）。

### 1.2 审计范围

**必备要素**：

1. 地址（省/市/区/路/号）；
2. 建筑名称；
3. 建筑面积（m²）；
4. 数据年份；
5. 分析指标清单；
6. 对标维度：行政机关层级 / 场馆类型 / 饭店星级与建设性质。

**模板**：

> 本次能源审计范围包含位于{地址}的{单位}{建筑}，建筑面积{面积}m²。
>
> 本次能源审计工作基于{起始年}—{结束年}整年及每月的电、水等能源账单及能耗统计数据，同时结合现场勘察所收集的建筑围护结构、各类用能设备资料、日常用能习惯等实际数据信息，对{建筑}年总能耗、单位建筑面积能耗、常规用能系统单位建筑面积电耗、人均综合能耗、人均电耗、单位用水量等进行分析计算，依据国家或地方能耗定额标准，对建筑用能现状进行总体评价。

**规则**：

- 公寓/饭店类删去"人均综合能耗、人均电耗"，改为"单位可比综合能耗、单位床年用水量"；
- 多栋项目逐栋列面积，或写"范围内共 N 栋，总建筑面积 X m²"；
- 建筑面积必须与第2章表2.1 一致。

### 1.3 审计周期

**两段式**（样本口径）：

```text
审计时间：{YYYY年M月—YYYY年M月}
审计周期：{YYYY年1月1日—YYYY年12月31日}
基准期：{YYYY年1月1日—YYYY年12月31日}
```

**规则**：

- 第三段标签固定为“**基准期：**”，不得增补“能耗对标”等前缀；
- 年月统一展开到日；基准期一般为一个完整自然年；
- 数据年份与 1.2 一致；
- 若某年只有部分数据，在 1.3 或 5.3 说明。

### 1.4 审计内容

**固定三段**：

1. 能源资源管理情况；
2. 能耗分析评价；
3. 节能潜力分析及建议。

**禁写**：把公共机构的"8 章内容"逐条罗列。

### 1.5 审计过程

**固定三段**：

1. 前期：调研表、资料收集、初步评估；
2. 中期：现场调研、数据核实、设备与系统确认；
3. 后期：数据汇总、用能分析、潜力挖掘、报告提交。

**规则**：可按项目实际情况补充，但不要写成"审计方法"清单。

### 1.6 审计依据

**唯一来源**：`tools/energy_audit/public_building_audit_basis.py`。
写章契约 `prepare_writing_context.py` 会把本项目适用的依据逐条展开；作者照抄，
不得再维护另一份固定清单。

**列表格式**：

- 统一使用 Markdown 无序列表，每项以 `- ` 开头；装配后为实心圆点；
- 不写“国家法规与导则”“浙江省规章”“定额标准”“用水定额”“项目资料”等分组标题；
- 不使用数字序号，不把多条标准合并到同一行。

**选择逻辑**：

1. 通用法律、能源审计导则、综合能耗计算和能源计量依据始终保留；
2. 行政机关、场馆首次引用写《行政机关、场馆能耗定额及计算方法》；科研办公、
   商务办公等不在标准直接列举范围的办公建筑，只写“**参照**《行政机关、场馆
   能耗定额及计算方法》”；
3. 旅游饭店首次引用写《旅游饭店单位综合能耗限额及计算方法》；专家公寓等
   公寓类建筑，只写“**参照**《旅游饭店单位综合能耗限额及计算方法》”；
   同一章后文统一写“该标准”，不得用 DB33 编号代替标准名称；
4. 有实际用水或给水系统时，加入《浙江省用（取）水定额》（2019年）；
5. 根据数据中实际存在的供暖空调、供配电、照明、给水系统加入相应技术规范；
6. 本报告包含既有公共建筑节能诊断与改造建议，因此纳入 JGJ 176-2009；
   若项目范围明确不含节能改造评估，应在选择器调用时排除改造类依据；
7. 调研资料统一写“**调研资料及其他相关资料。**”，不得展开账单、设备台账、
   现场勘察记录等长清单。

**适用范围说明（必写）**：

- 《行政机关、场馆能耗定额及计算方法》的适用对象是行政机关、场馆；
  《旅游饭店单位综合能耗限额及计算方法》的适用对象是旅游饭店；
- 科研办公、专家公寓等非标准列举对象，只能写"**参照**"对应标准全名，并说明参照理由；
- 不得把"参照"写成"依据"，也不得伪装成标准直接适用对象。

**禁写**：

- DB37 系列；
- 山东地方供热办法；
- 未核验的标准编号/年份。

## 第2章 建筑概况

> 2026-10-20 用户确认：本章章名固定为"**建筑概况**"，不得使用"公共机构概况"。

### 2.1 基本情况

**内容**：

- 单位/园区背景与职能；
- 建筑功能定位（科研办公/公寓/场馆）；
- 本次审计对象与院区关系。

**规则**：

- 不写"公共机构"属性、编制、经费来源等公共机构专属信息；
- 单位简介控制在 2~3 段，不复制官网长文；
- 首段必须出现建筑全称。

### 2.2 建筑物概况

**必备表**：逐栋一张 `表2.N {建筑名}建筑信息统计`，固定为 **4 列、8 行、
16 个字段**的键值表，无表头行、全表不加粗：

| 行 | 第一组字段 | 第二组字段 |
|---|---|---|
| 1 | 建筑物名称 | 建筑面积（m²） |
| 2 | 建筑地址 | 投用年份 |
| 3 | 建筑层数 | 建筑高度（m） |
| 4 | 建筑结构形式 | 建筑透明围护结构 |
| 5 | 夏季空调冷源 | 冬季供暖热源 |
| 6 | 夏季空调末端形式 | 冬季供暖末端形式 |
| 7 | 建筑外墙保温 | 生活热水系统 |
| 8 | 建筑给水系统 | 能耗在线监测系统 |

**规则**：

- 多栋建筑逐栋一张表，按 `表2.1`、`表2.2`……连续编号，不合并为宽表；
- 字段顺序固定；未知字段写"—"，不得删除字段或自行补写；
- 字段值照录 `data.json → buildings[]` 原值，不补“年”、单位、材料、现状或解释性文字；
- `window_type` 在本族表中只显示为“建筑透明围护结构”；
- 不设“建筑功能”“建筑功能分区”“是否中央空调”“消防给水系统”；
- “投用年份”等基础数据继续供第5章指标修正使用，但表内只展示批准字段；
- 图2.1 单位/院区外观；图2.2 平面布置；图2.3 主体建筑照片。

### 2.3 能源资源利用情况

**按四类写**：

1. 用电系统：供暖空调、照明、办公、特殊用能、变配电；
2. 用水系统：生活用水、工艺用水、灌溉、空调补水；
3. 燃气系统：厨房炊具/蒸汽锅炉；
4. 用油系统：公务车。

**规则**：

- 设备名与第6章一致；
- 只写"有哪些系统"，不写运行评价；
- 没有的能源写"无"或省略。

## 第3章 能源资源管理状况

### 3.1 机构职责

**三层写法**：

1. 决策层：资产部/后勤/能源管理领导小组；
2. 执行层：服务中心/物业；
3. 监督层：财务/审计/考核。

**必备内容**：

- 谁负责抄表；
- 谁负责统计；
- 谁负责缴费/分摊；
- 谁负责设备维保。

**禁写**：只列部门名称、不写职责。

### 3.2 目标方针

**内容**：

- 节能目标/方针；
- 收费或结算机制（如有）；
- 能耗定额/考核（如有）。

**规则**：

- 有电费分摊/结算机制的，写清单价、分摊系数、盈亏（样本 AB 座表3.1）；
- 没有的写"未建立"；
- 不写与建筑无关的公共机构节能指标。

### 3.3 能源资源管理成效与问题

**结构**：

1. 成效（2~3 条，带事实）；
2. 问题（2~3 条，管理类）；
3. 过渡句（引向第7章）。

**问题范围**：

- 无专职/兼职能源管理员；
- 无节能奖惩制度；
- 无培训/宣传；
- 无在线分析/预警；
- 收费/分摊机制不科学。

**禁写**：设备能效、照明改造等设备问题（归第6/7章）。

## 第4章 能源资源计量及统计状况

### 4.1 计量体系

**固定条文**（GB/T 29149）：

- 一级：进出单位/建筑总表；
- 二级：按行政办公区、业务区、保障区、特殊功能区计量；
- 三级：主要用能系统/设备单独计量。

**规则**：可沿用固定文字，不按项目改写。

### 4.2 计量器具配备及管理

**必备内容**：

- 电表数量、水表数量；
- 覆盖层级（总表/建筑/楼层/分项）；
- 是否满足分户、分区、分系统；
- 器具安装位置与检定。

**规则**：

- 数量取项目台账；
- 缺哪一级写哪一级；
- 不写"全部满足"除非有依据。

### 4.3 能源资源统计情况

**必备内容**：

- 在线监测系统名称/功能；
- 抄表频率；
- 统计汇总流程；
- 数据保存/上报。

**规则**：无在线系统写"人工抄表"；有系统写系统名与覆盖范围。

### 4.4 能源资源统计成效及问题

**结构**：成效 + 问题。

**常见问题**：

- 人工分析滞后，漏水/异常未及时发现；
- 部分表计未接入在线系统；
- 分项计量不完整；
- 数据颗粒度不足（只有总表）。

**禁写**：与计量无关的设备问题。
