# 第6章参考结构（基于省第二人民医院能源审计报告）

## 总体结构

```
第6章 主要能源资源利用系统分析

6.1 用电系统运行分析
  总述：列出所有用电设备类别（空调/照明/办公/热水器/厨房/医疗设备等）
  
  空调与供暖系统
    ├── 冷源描述：具体冷源类型 + 末端形式 + 主要设备名称/数量
    ├── 热源描述：热源类型 + 末端形式 + 运行时间（6月~9月制冷/11月~3月供暖）
    ├── 设备照片（图6.1）
    └── 设备清单表（表6.1）
  
  照明系统
    ├── 灯具类型列举 + 数量
    ├── 运行时间 + 控制方式
    ├── 设备照片（图6.2）
    └── 设备清单表（表6.2）
  
  办公设备系统
    ├── 设备名称 + 数量
    └── 设备清单表（表6.3）
  
  大型医疗设备 / 其他用电设备（按机构类型）
    ├── 医疗：CT/MRI/... + 表6.N
    ├── 非医疗：热水器/电梯 + 表6.N
  
  厨房设备（如有）
    ├── 设备名称
    └── 设备清单表

  信息机房系统
    ⚠️ 提示用户补充：机房面积/机柜/服务器/UPS/精密空调/是否单独计量

  变配电系统
    ⚠️ 提示用户补充：变压器型号/容量/数量/位置/节能型变压器

6.2 用水系统运行分析
  用水主要为医疗用水/生活用水/灌溉用水。生活用水由市政自来水直供。

6.3 其他用能系统运行分析
  餐厅（外包/独立计量）+ 公务车（数量/结算方式）

6.4 室内环境检测
  检测条件 + 标准对比表（GB 50034-2024 + GB/T 18883-2022）+ 结论
```

## 写作要点

1. **每个子系统独立成节**，有H3标题，不混在一起
2. **设备描述要具体**：型号、数量、参数（不要只说"包括XX等"）
3. **运行时间要明确**：供冷/供暖起止月份、每天时长
4. **冷源/热源从建筑数据读取**：从 buildings[].cooling_source / heating_source 等字段获取
5. **照片嵌入**：设备照片在设备表之前
6. **无数据子系统**：明确提示用户补充，格式为 `⚠️ 请提供XX信息：...`
7. **表格编号连续**：表6.1, 表6.2, ...
