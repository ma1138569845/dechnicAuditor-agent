# 第6章 用电系统运行分析 — 分系统写作规范

## 总结构

```
6.1 用电系统运行分析
  总述段落（无具体数字，只列系统名称）
  ├── 空调与供暖系统 (H3)
  │   ├── 设备描述（名称 + 数量 + 功能 + 运行时间）
  │   ├── ⚠️ 节能改造提示
  │   ├── 📷 设备照片（一行两张）
  │   └── 表6.1-N 设备清单
  ├── 照明系统 (H3)
  ├── 办公设备系统 (H3)
  ├── 其他用电设备 (H3)
  ├── 变配电系统 (H3，无数据时提示用户提供)
  └── 信息机房系统 (H3，无数据时提示用户提供)
```

## 总述段落

格式：`{单位}用电系统主要包括{系统1}、{系统2}、...系统等。`

**规则**：只列系统名称，不出现任何数字。例如：
- ✅ "莘县政府用电系统主要包括空调与供暖、照明、办公设备、其他用电设备系统等。"
- ❌ "莘县政府用电系统主要包括空调102台、照明432套..."

## 分系统写作模板

### 有设备的系统（空调/照明/办公/其他用电）

```
{sub_name} (H3)

{sub_name}包括{设备名1}、{设备名2}，共{N}台，{功能描述}。系统运行时间为{时间段}。

⚠️ 请提供{sub_name}的节能改造情况：是否进行过节能改造、改造措施及效果。

📷 请提供{sub_name}照片。

表6.1-{idx}  {sub_name}清单
```

### 无数据的系统（变配电/信息机房）

```
{sub_name} (H3)

⚠️ 请提供{sub_name}信息：{具体需要什么数据}。
```

## 空调系统写法示例

> 空调与供暖系统包括中央空调、柜机、挂机，共102台，其中中央空调6台，主要承担建筑公共区域的夏季制冷和冬季供暖功能；分体式空调（柜机、挂机）96台，分布于各办公室和功能用房。系统运行时间为每年6月至9月制冷、11月至次年3月供暖，每天约8小时。

## 照明系统写法示例

> 照明系统包括照明灯具，共432套，主要包含办公室照明、公共区域照明及室外照明灯具。办公区域照明运行时间约为每天8:00-18:00，公共走廊采用声控或定时控制。照明系统采用LED平板灯、筒灯等高效光源，具备基本的节能控制措施。

## 格式要求

- H3: 宋体 12pt 加粗
- 表格: 表6.1-1, 表6.1-2, ... 编号递增
- 表格名称: `{sub_name}清单`（不是"{sub_name}设备清单"——避免"设备设备"重复）
- 照片提示: `📷 请提供{sub_name}照片。`

## Pitfalls

1. "其他用电设备设备清单" → 应写"其他用电设备清单"（去重"设备"）
2. 所有 `⚠️` 和 `📷` 提示必须有 sub_name 变量代入，不能写死
3. 变配电系统和信息机房系统默认无数据，始终提示用户提供
