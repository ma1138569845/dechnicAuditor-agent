# 第6.1节分系统写作规范

## 总原则

6.1用电系统 = **1段总述 + N个分系统**

总述只列系统名称，不写具体数字。分系统逐个详述。

## 结构

```
6.1  用电系统运行分析

  总述: "XX单位用电系统主要包括空调与供暖、照明、办公设备等系统。"

  空调与供暖系统 (H3)
    设备描述: 具体名称 + 数量 + 功能 + 运行时间
    节能改造提示: "⚠️ 请提供XX系统的节能改造情况..."
    照片: 一行两张（如有）
    设备清单表: 表6.1-N

  照明系统 (H3)
    同上结构

  办公设备系统 (H3)
    同上结构

  其他用电设备 (H3)
    同上结构

  变配电系统 (H3)
    无设备数据 → 仅提示用户补充信息

  信息机房系统 (H3)
    无设备数据 → 仅提示用户补充信息
```

## 分系统内容要素

每个有设备的分系统必须包含：

1. **设备描述**: 名称列表 + 总数 + 功能说明
   ex: "空调与供暖系统包括中央空调、柜机、挂机，共102台，其中中央空调6台..."
2. **运行时间**: 季节性 + 日运行时长
   ex: "系统运行时间为每年6月至9月制冷、11月至次年3月供暖，每天约8小时"
3. **节能改造提示**: 统一格式 `⚠️ 请提供XX系统的节能改造情况`
4. **照片提示**: `📷 请提供XX系统照片`
5. **设备清单表**: 序号/设备名称/规格/数量/备注

## 无设备数据的分系统

仅提示用户补充信息，不给虚假描述：
ex: "⚠️ 请提供变配电系统信息：变压器数量、型号、容量..."
    "⚠️ 请提供信息机房系统信息：机房面积、机柜数量..."

## H3标题格式

- 字体: 宋体 12pt 加粗 左对齐
- 全局H3格式为宋体

## Pitfalls

1. **不能把设备全混在一个段落里** — 必须分系统
2. **总述不要说具体数字** — 只说有哪些系统
3. **不要编造节能改造信息** — 没数据就显式提示用户提供
4. **表号6.1-X要递增** — 不要全写成6.1-6
