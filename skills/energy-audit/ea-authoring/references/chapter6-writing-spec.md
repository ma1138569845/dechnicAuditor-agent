# 第6章 用电系统分析 — 写作规范 (v2.0)

## 6.1 用电系统运行分析

### 总体结构
```
6.1 用电系统运行分析 (H2)
  ├── 总述段落（不带具体数字，只列举系统名）
  │   "XX单位用电系统主要包括空调与供暖、照明、办公设备、其他用电设备系统等。"
  ├── 分系统 (H3，按以下顺序)
  │   ├── 空调与供暖系统
  │   ├── 照明系统
  │   ├── 办公设备系统
  │   ├── 其他用电设备
  │   ├── 变配电系统    ← 通常无数据，⚠️提示
  │   └── 信息机房系统  ← 通常无数据，⚠️提示
  └── 6.2 用水系统运行分析 (H2)
      6.3 供暖系统运行分析 (H2)
```

### 分系统写作模式

每个有设备的分系统按以下顺序：
1. **设备描述段**: 具体设备名称 + 每种数量 + 功能描述 + 运行时间/季节
2. **节能改造提示**: ⚠️ 请提供{sub_name}的节能改造情况：是否进行过节能改造、改造措施及效果。
3. **设备照片**: 📷 请提供{sub_name}照片。（有照片则嵌入，一行两张）
4. **设备清单表**: 表6.1-N {sub_name}清单

无设备的分系统（变配电、信息机房）：只显示⚠️提示信息，不生成表格。

### 代码实现要点
- equipment按category分类：空调/照明/办公/热水器 → 各自独立的分系统
- 厨房设备属于用气系统，不在用电系统出现
- sub_idx从1递增，表号=表6.1-{sub_idx}
- _handled=True标记后跳过通用渲染，但section_num仍需++
- 6.1的H2标题在自动推断代码块中显式添加 `_add_heading_2("6.1  用电系统运行分析")`
