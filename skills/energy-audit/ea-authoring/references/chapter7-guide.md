# 第7章 节能效果与节能潜力分析 · 写作逻辑

> 核心机制：7.1 问题清单与 7.2 措施清单一一对应；问题来源于第6章现场查看发现 + 用户提供的痛点；措施从措施库选取并对应展开。

## 7.1 用能系统现状分析（问题逐条）

> 每条问题结构：**小节标题（现象概括）→ 段落（现象+原因+影响+建议方向）→（可选）现场照片**。
> 小节标题格式：7.1.X [问题概括，8-12字]，如"建筑保温效果差""照明灯具能效低，智能化程度低"。

问题段落模板：
[机构]为[结构形式]建筑，[现状描述]，[影响，如：围护结构保温性能差导致建筑供冷、供热能耗较高，且房间舒适度较差]，[建议方向，如：建议增加建筑物外墙保温]。

**常见问题库**（按现场发现选取，不编造未发现的问题）：

| 问题 | 触发条件 | 正文要点 |
|------|---------|---------|
| 建筑保温效果差 | 建筑外墙无保温（表2.1） | 砖混结构、外墙未保温 → 供冷供热能耗高、舒适度差 → 建议增加外墙保温 |
| 照明灯具能效低，智能化程度低 | 荧光灯为主、无集中控制 | LED占比少、长明灯/无效照明 → 能源浪费 → 建议LED替换+智能控制 |
| 空调系统老化，缺少智能控制 | 主机服役15年以上/无自控 | 老化能效低；无变频、无联动；末端三速开关控温不精确 → 建议更新+自控改造 |
| 可再生能源利用率低 | 无光伏/热泵等 | 无可再生能源系统 → 建议空气源热泵/屋顶光伏 |
| 暖通管网水力不平衡 | 现场反馈冷热不均 | 部分房间过热、部分供热差 → 系统调节能力不足 → 建议加装平衡阀 |
| 存在淘汰目录设备 | 设备清单含Y2电机等 | 属《高耗能落后机电设备（产品）淘汰目录》 → 能耗高效率低 → 建议及时更新淘汰 |

## 7.2 节能潜力分析及建议（措施逐条，与7.1一一对应）

> 每条措施结构：**小节标题（措施名）→ 技术方案描述段**。
> 措施库文本为标准技术描述，选取后按机构实际调整规模参数（数量/面积等）。

### 措施库（8类）

**1. 建筑外墙保温**（↔建筑保温效果差）
保温材料可选择真空绝热板。真空绝热板以无机材料为芯材，用复合阻气膜作包裹材料，经抽真空、封装等工艺制成的建筑保温用板状材料，称为STP真空绝热板。STP真空绝热板较传统建筑保温材料更加有效地阻断了热量传递（热传导、热对流、热辐射），达到保温隔热效能的最大化，使建筑节能减排目标的实现得到了有力保障。

**2. 暖通空调系统改造**（↔供暖调节受限/空调老化）
针对[市政供暖温度调节受限、使用灵活受限等问题]。建议[利用场地条件]建设空气源热泵系统，并利用原有管道和末端，冬季使用空气源热泵系统替代现有的集中供暖，夏季作为中央空调系统冷源，原有冷水机组作为备用冷源，并建设节能控制系统。

**3. 中央空调智慧节能管控系统建设**（↔缺少智能控制）
中央空调冷源形式为[冷源类型]，当前无集中控制系统，仅依靠人工进行简单的设备启停，无变频控制以及历史运行数据统计功能。建议建设中央空调节能控制系统，根据室外环境及室内负荷需求，主动预测并调节系统运行状态，进行冷冻（却）水温、水泵频率、主机台数、风机频率等参数调节，保证舒适度的前提下，精准供能，同时，系统具备自适应、自学习的功能，保证系统在任何工况下的能效（EER）最优。

**4. 空调末端改造**（↔末端控制粗放）
空调系统[末端]控制器为[现状，如：三速开关]，仅能简单控制[风量]，无法对室内温度进行精确显示、数据上传、远程控制等。建议将当前空调末端控制器改造为联网型温控器，并进行统一的联网集中控制，实现远程启停和室内温度精确控制，并将空调末端与供冷供暖系统进行联动控制，降低中央空调系统运行能耗。

**5. 暖通管网平衡调节**（↔水力不平衡）
当前暖通管网水力不平衡，导致[冬季供暖流量不均匀等]，建议在供暖效果过热的房间末端管路上增加平衡调节阀，调节流量，保证供暖效果均衡。

**6. 照明系统改造**（↔照明能效低）
在保证照度的情况下，建议将现有的[N]个[普通荧光灯、吸顶灯]统一替换为高效LED灯具，减少灯具耗电。同时，对照明系统进行智能化改造，通过加装智能照明控制器、时控器、感应模块等，实现分时、分区、感应控制。根据功能区域不同，实施针对性的照明控制措施，如走廊与楼梯间采用感应控制，感应控制采用人体红外或微波雷达与灯具联动，实现无人时自动关灯，延迟时间可调；[地下机房等特殊区域]采用亮度自动调节，高峰时段全亮度模式，低谷时段自动调暗或关闭非必要区域。

**7. 光伏发电系统建设**（↔可再生能源利用率低）
为提高可再生能源利用率，建议利用[屋顶资源]建设光伏发电系统，自发自用，减少市电依赖，不仅能够降低运营成本、减少碳排放，还能起到示范引领、推动绿色低碳转型、提升社会形象的作用，具有显著的经济、环境和社会效益。

**8. 管理与行为节能**（固定兜底项，末条必选）
据统计，建筑用能统计中，因管理和行为不当引起的能源浪费约占建筑总能耗的5%-10%左右。因此，进一步加强管理和行为节能管控具有很大的必要性。将资源节约理念和要求贯彻落实到公共机构日常工作中，动员公共机构全体职工，倡导节约文化，营造节约氛围，提高资源利用率。
1.提高行为节能意识，电脑、打印机、饮水机等设施不使用时及时关闭电源，减少不必要的设备用电消耗；
2.合理设定冬、夏季房间温度，夏季不低于26℃，冬季不高于20℃；
3.设专人巡检设备的整体运行状况，按计划对设备的运行状况进行检测，降低设备故障率，确保设备处于高效运转状态，减少能源消耗；
4.建立严格的节电、节水规章制度，培养良好的节电、节水习惯等。

## 生成规则

1. 7.1 问题数量 = 7.2 措施数量 − 1（"管理与行为节能"为固定末条，不对应具体问题）
2. 措施顺序按"问题严重度/改造收益"排序，保温类在前、行为类收尾
3. 第 8 章审计结论中的"建议共计N条" = 7.2 实际措施数（含管理与行为节能）
4. 措施中的数量参数（替换灯具数、屋顶面积等）来自设备清单/建筑数据，无数据则不写具体数量

### ⚠️ 事实一致性铁律（违反即否决）

1. **问题/措施必须与第2章建筑参数一致**：
   - 表2.1 外墙保温=**有** → 禁止提"围护结构保温改造"问题与措施（历史事故：外墙有保温的楼被套上"外墙无保温+屋面未设保温"问题，建议不成立）；
   - 冷源/末端类型、供暖形式必须与表2.1 一致（市政供暖+散热器项目不得诊断"制冷机房群控"）。
2. **措施诊断必须与用能系统实际匹配**：
   - 天然气为厨房炊事用气 → 禁止写"燃气锅炉效率下降、清洗锅炉换热面、测排烟温度"（历史事故：无锅炉项目套用锅炉诊断模板）；
   - 有信息机房的项目才可提机房相关措施。
3. **措施选取必须有现场依据**：问题来源于第6章现场查看 + 用户提供痛点，禁止按措施库全量搬套。

### 经济测算要求

每条措施须附**经济测算**（投资、年收益/节能量、回收期），格式：

[措施方案描述]。经测算，[改造规模描述]，预计投资[X]元，年收益/年节能量为[X]，投资回收期为[X]年。

- 测算数据来源：现场勘查数据、设备清单参数、当地电价/能源价格——**无测算数据时标注【待补充】，禁止编造百分比或金额**（历史事故："预计5%~15%节能"式模板话术无任何测算依据）。
- 已交付报告示例：光伏（1,650 m²、167 kWp、年发电25万kWh、投资417.45万、回收4.1年）；暖通群控（投资7.97万、年收益1.79万、回收4.44年）；地下车库感应照明（778根灯管、日均182→123 kWh、投资3.89万、回收3.28年）。
