# 报告总体结构与章间联动规则

> 样例基准：省贸促会能源审计报告（党政机关类）。全文 8 章 + 8 附录，约 450 段、30 表。

## 全报告结构树

```
封面（机构名称表：审计单位资质表、审计组成员表）
第1章 能源审计执行概要
  1.1 审计目的 / 1.2 审计范围 / 1.3 审计周期 / 1.4 审计内容 / 1.5 审计过程 / 1.6 审计依据
第2章 公共机构概况
  2.1 基本情况（机构简介段+办公楼外观照片）
  2.2 建筑物概况（建筑描述段 + 表2.1 建筑基本信息）
  2.3 能源资源利用情况（用能类型+系统总览）
第3章 能源资源管理状况 → 复用 energy-audit-report-chapter skill
  3.1 机构职责 / 3.2 目标和方针 / 3.3 成效与问题
第4章 能源资源计量及统计状况
  4.1 计量体系 / 4.2 计量器具配备及管理（表4.1）/ 4.3 统计情况 / 4.4 成效及问题
第5章 能源资源消费/消耗指标分析
  5.1 概况（能源流向图）
  5.2 消耗数据（5.2.1用电/5.2.2用水/5.2.3用暖/5.2.4其他/5.2.5费用 表5.1）
  5.3 消耗指标（5.3.1~5.3.4，表5.2~5.5 定额对标）
第6章 主要能源资源利用系统分析 → 复用 D:\chapter6 规范
  6.1 用电系统（分系统+表6.1~6.4）/ 6.2 用水系统 / 6.3 其他用能 / 6.4 室内环境检测（表6.5~6.7）
第7章 节能效果与节能潜力分析
  7.1 用能系统现状分析（问题逐条）/ 7.2 节能潜力分析及建议（措施逐条）
第8章 审计结论（聚合复用）
附录1 建筑基本信息及设备统计表
附录2 建筑能耗数据信息表（三年逐月账单，每建筑一张表）
附录3 现场运行记录 / 附录4 暖气报停说明 / 附录5 油费充值发票
附录6 室内环境测量表 / 附录7 室内空气质量指标及要求 / 附录8 折标煤参考系数
```

## 章间联动规则（生成时必须校验）

| 联动 | 规则 |
|------|------|
| 1.2 ↔ 5.3 | 1.2 审计范围列举的指标名（单位建筑面积非供暖能耗、常规用能系统单位建筑面积电耗、人均综合能耗 + 取水指标名）必须与 5.3 实际生成指标一致；取水指标名按机构类型自适应（权威映射见 energy-audit-core/references/standards-values.md） |
| 2.3 ↔ 第6章 | 2.3 用能系统总览的设备列举 = 第6章各分系统设备汇总 |
| 4.1 ↔ 4.4 | 4.4 成效段复用 4.1 计量现状段要点 |
| 5.2 ↔ 5.3 | 5.3 计算表的"年用量"行数据与 5.2 正文数值一致 |
| 5.3 ↔ 8 | 第8章指标评价条目 = 5.3 各指标结论段**原文复制**（含数值、标准号、三档评价） |
| 7.1 ↔ 7.2 | 问题与措施一一对应（7.1.X 建筑保温差 ↔ 7.2.X 外墙保温） |
| 7.2 ↔ 8 | 第8章建议罗列 = 7.2 各小节标题原文 |
| 6.1 设备 ↔ 7.1 问题 | 7.1 的设备老化/淘汰问题应来自 6.1 现场查看发现（如 Y2 系列电机、20年以上老设备） |

## 图表编号规则

- 图号：`图X.Y 说明文字（单位：xx）`，按章内顺序递增（图5.1~5.8、图6.1~6.5、图7.1~7.3）
- **禁止 a/b 后缀编号**（历史事故：图5.2a/图5.3a——逐年图与逐月图必须按顺序连续编号，如逐年=图5.2、逐月=图5.3）
- 表号：`表X.Y 表名`，按章内顺序递增（表2.1、表4.1、表5.1~5.5、表6.1~6.7）
- 先正文引用（"如图5.2所示"/"见表5.1"）后插入图表
- 设备照片布局：2×N 表格网格排版，每格一张照片+（n）设备名称小注，网格下方统一图注
- 费用占比图：每个审计年度一张饼图（三年三张），禁止只给最近一年

## 封面与前置信息表规则（⚠️ 禁止【待补充】交付）

- 能源审计机构信息表（机构名称/地址/负责人/联系方式）、审计组人员名单、配合人员名单**不得以【待补充】占位交付**：
  - 机构名称/地址查 `ts_register_dept`；负责人/联系方式**必须向用户提问取得**；
  - 审计组/配合人员查 `ts_project_audit_user` / `ts_project_audited_user`，无记录必须向用户提问；
  - 历史事故：封面 3 处待补充 + 人员表整表待补充的版本曾作为成果输出。
- 审计时间、报告日期、委托方信息缺失时同样向用户提问，不得猜填。

## 排版规则（Word 输出）

- 章标题（H2）：第X章+双空格+章名
- 节标题（H3）：X.Y+空格+节名
- 小节标题（H4）：X.Y.Z+空格+小节名（部分小节用正文加粗段代替，如 5.3.2、7.1.1）
- 正文：宋体，首行缩进 2 字符
- 图片：居中；图注 10pt 居中
- 表格：表名居中位于表格上方

## 附录生成规则（强制项，缺一不可交付）

- **附录1（必生成）**：建筑基本信息表（同表2.1 扩展）+ 设备统计汇总
- **附录2（必生成）**：每栋建筑一张"月度能耗信息表"（三年逐月账单：电量/电费/水量/水费/燃气量/燃气费/油量/油费/供暖量/供暖费，12 个月+合计行）——审计报告核心附件，数据不全时向用户索取账单补齐，禁止省略整个附录（历史事故：生成版无任何附录）
- 附录3~5：用户提供现场记录/说明/发票图片（无则省略并在正文说明）
- **附录6（必生成）**：室内环境检测原始记录表（实测数据来自现场检测；无检测时向用户索取或标注未检测）
- **附录7（必生成）**：室内空气质量指标要求（固定标准表）
- **附录8（必生成）**：折标准煤参考系数表（固定，见 energy-audit-core/references/standards-values.md（权威单点））
