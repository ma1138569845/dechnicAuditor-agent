## 法院/党政机关实例（原 examples/court-agency-audit）

2026-08 烟台经开区法院实战验证。母版：`E:/杂/日照市岚山区人民法院能源审计报告.pdf`（53页），烟台经开区法院报告已按此生成。

### 适用

党政机关、法院、检察院等机关类公共机构。区别于市州模板 0–11 章骨架，本类报告采用 **8 章 + 7 附录** 结构（2026-09-05 定稿：1建筑基本信息及设备统计表 / 2能耗数据信息表 / 3电费、水费、油费、燃气费充值发票 / 4室内环境测量表 / 5空气质量判定方法 / 6室内空气质量指标及要求 / 7折标准煤参考系数；**无发票照片时无附录3，后续序号依次前移为 6 附录**）。

### 报告结构（8章+7附录，无发票时6附录）

1. 能源审计执行概要：1.1目的 / 1.2范围（建筑清单+审计期数据基础）/ 1.3周期（审计时间+审计期+基准期三段）/ 1.4内容 / 1.5过程（前期调研表→中期现场核实→后期汇总）/ 1.6依据（国标+省级规章+地方供热办法）
2. 公共机构概况：2.1基本情况（职能/信用代码/用能人数，段落后紧跟图2.1单位整体外观）/ 2.2建筑物概况（每栋键值对表）/ 2.3能源资源利用情况
3. 能源资源管理状况：3.1机构职责 / 3.2目标方针 / 3.3问题与成效
4. 能源资源计量及统计状况：4.1计量体系（GB/T 29149 分户/分区/设备计量要求）/ 4.2器具配备及管理 / 4.3统计成效及问题
5. 能源资源消费/消耗指标分析：5.1流向图 / 5.2消耗数据（电/水/热/其他/费用表5.1+占比）/ 5.3指标（4个，见下）/ 5.4建筑能耗基准（核定办法）
6. 主要能源资源利用系统分析：6.1用电系统（空调供暖/照明/办公/其他/信息机房/变配电，各配设备清单表）/ 6.2用水 / 6.3用热 / 6.4其他（食堂燃气+公车油）/ 6.5室内环境检测
7. 节能效果与节能潜力分析：7.1用能系统现状问题（5条左右）/ 7.2建议（7条，各配预计节能率）+ 7.2.8节能率汇总
8. 审计结论：4指标评价逐条 + 问题清单 + 建议清单
附录：1建筑基本信息及设备统计表 / 2能耗数据信息表 / 3电费、水费、油费、燃气费充值发票（照片）/ 4室内环境测量表 / 5空气质量判定方法（A/B/C/D表）/ 6室内空气质量指标及要求（GB/T 18883-2022）/ 7各种能源折标准煤参考系数（无发票照片时无附录3，后续序号依次前移）

### 定额标准（DB37/T 2672-2019，2026-08 已 web_search 验证原文）

烟台/日照适用 **市级以下 A 区**（A 区=沿海温和，B 区按 DB37/5026）：

| 指标 | 约束值 | 基准值 | 引导值 |
|---|---|---|---|
| 单位建筑面积非供暖能耗 kgce/(m²·a) | 20.0 | 11.9 | 6.5 |
| 常规用能系统单位建筑面积电耗 kWh/(m²·a) | 67.4 | 39.5 | 20.0 |
| 人均综合能耗 kgce/(p·a) | 1197.8 | 781.0 | 453.7 |
| 供暖能耗（市政集中供热按热计量）kgce/(m²·a) | 12.7 | 11.1 | 8.3 |

> 定额数值以 energy-audit-core/references/standards-values.md 为准，此处为法院实例示例。

- 市级 A 区数值（21.9/14.9/7.2）与市级以下 A 区（20.0/11.9/6.5）**不同**；省级 B：25.5/16.6/9.6。完整矩阵见 energy-audit-core/references/standards-values.md
- 2019 版已**删除**人均综合水耗定额；机关取水量对标 DB37/T 4452-2021（通用值 25 / 先进值 10 m³/(p·a)）——参考报告做法，非严格匹配（该标准为教育卫生服务业）
- 标准起草单位含同方德诚（山东）科技股份公司；EUE 定额 2.2/1.8/1.4
- 注意：公安政法类单列是辽宁标准（DB21/T）做法，山东未单列法院

### 折标系数（山东 DB37/T 系列附录 B，与 GB/T 2589 的 1.33 不同！）

电 0.31（供电煤耗）/ 天然气 **1.2143** / 热力 0.03412 kgce/MJ（=34.12 kgce/GJ）/ 汽油 1.4714 / 柴油 1.4571 / 液化石油气 1.7143 / 原煤 0.7143。

> 陷阱：DB 库 energy_main.standard_coal_coefficient 天然气存 1.3300，与山东公共机构口径 1.2143 不同——写报告统一用 1.2143（参考报告+省标附录B），附录7系数表同步（无发票时附录6）。

### 指标口径（日照版做法）

- 非供暖能耗 = 总电量 × 0.31 ÷ 建筑面积（简化口径：未剔供暖循环泵电耗与机房/厨房特殊用能，与标准定义有出入但日照报告即此做法）
- 常规电耗 = 总电量 ÷ 建筑面积
- 人均综合能耗 =（电×0.31 + 油t×1000×1.4714 + 热GJ×1000×0.03412 + 气×1.2143）÷ 用能人数，水不计入综合能耗
- 人均取水量 = 年取水量 ÷ 人数
- 建筑能耗基准（《山东省公共建筑节能改造节能量核定办法》4.0.2）：逐年递增/递减 → 取最近一年；±10% 内波动 → 取三年平均

### 数据中心数据要点（烟台实战）

- 客户定位：`ts_institution_project.audited_name` / `ts_customer_info.customer_name` 模糊匹配；**勿用 audit_dept_name（那是审计机构名，如“同方德诚测试公司-1”）**
- **多版本陷阱**：energy_main / build / meter / 设备表均有 is_draft + version_code 多版本 → 取 is_draft=0、deleted=0、version_code 最大（PL2026080402 > 0401）；2025 电量曾两版并存（1040085 vs 1011885）取最新版
- **费用单位混乱**：unit 元/万元混标，total_value 按量级判断（752854 实为“元”）；data_type 2=费用、7=热力费、8=油费
- **费用-用量交叉验证**：供热按计量表缴费时用 scene.heat_price 反推（89.61 元/GJ）——烟台 2024/2025 用量与费用录入交叉，修正后三年单价全部吻合；修正必须在报告 5.2.3 加表注说明
- 用能人数：`ts_institution_scene.work_staff`（ts_annual_energy_user 常空表）
- 供暖信息：scene.heat_pay_type（按计量表/按面积）+ heat_price + 采暖期（烟台：11月16日—次年3月31日，《烟台市供热管理办法》）
- 逐月数据：ts_institution_energy_data 的 energy_value 可能全空（烟台缺失）→ 如实写“未获取完整逐月记录”，不要编
- 能源代码映射（勿信表头）：01=水（常误标天然气）、25=天然气、45=电、50=热力、300301=汽油
- 设备：12 个 `ts_institution_device_*` 分类表（air/light/office/other/power/special/substation/td/terminal…），按 (名称, 功率, 数量) 去重取最新版；照明名称在 other_device_name 字段（device_name 全是“其它特殊灯具等”）
- 附件/发票照片：采集自 ts_institution_energy_invoice（主表）+ ts_institution_energy_invoice_image（明细，record_id 关联，file_id→ts_attachment.group_id→base_url 下载）；分类'缴费发票'，caption 带能源类型+期间（如"电费 1月~2月"），附录按 caption 前缀分组排列（2026-09-04 接入，此前误判'外部不可下载'实为未查 image 明细表）

### 报告编写要点

- 人员名单/负责人/联系方式 →【待补充】，不编造真人姓名；审计机构用“同方德诚科技有限公司”（项目库 audit_dept_name 是测试数据不可用）
- 缺失数据（2023/2024 水量、逐月、实测环境）→ 明确标注【数据缺失，待补充】并在相关章节说明，不编造
- 人均综合能耗超标（用能人数少→人均分摊高）→ 如实评价“高于约束值”并解释原因
- 节能率估算参考日照：能耗监测 0.5-1% / 照明改造 1.1% / 空调主机 3.7% / 末端温控 0.7% / 光伏 10-15%（以屋顶测算为准）
- 用能人数=351（烟台）这种场景下，指标评价注意约束/基准/引导三层关系表述：低于约束但高于基准=“低于约束值”
- 封面信息表（第一张表）：报告名称/被审计单位/审计机构/审计期/报告日期

## 医院实例（原 examples/hospital-audit）

母版结构同党政机关版（8章+7附录，无发票时6附录），见 `audit-examples.md`。本篇记录医院差异点。

### 医院特点（vs 党政机关）

- 全年全天候运行；特殊用能系统：大型医疗设备（CT/MRI）、手术室净化空调、消毒供应蒸汽、洗衣房——定额口径上计入综合能耗、不计入非供暖能耗与常规电耗（独立计量时可剔除）
- 用能人数口径：职工+住院+门诊折算（DB scene.work_staff，岚山=3405人）
- 建筑面积/床位/职工数：DB 常缺（岚山 build 表空）→ 用公开资料并表注“据医院公开资料，以院方核定为准”（岚山：43000m²、500床、806职工）
- 能耗品种常只有电/水/天然气（岚山无热力/油记录；天然气用途消毒/食堂/供暖未分项）

### 定额标准

- **DB37/T 2673-2019《医疗机构能源消耗定额标准》**（鲁事管办发〔2021〕54号确认医院按此执行）：二级医院具体数值（非供暖能耗/电耗/人均综合能耗约束-基准-引导）网上无免费全文——**拿不到就按技能原则用【待核验】占位并显式提示用户**，不编造。**三级医院基准值已核验**（2026-08 省机关事务管理局官网绿色低碳公共机构案例引用，淄博市妇幼保健院申报文）：单位建筑面积非供暖能耗基准值 **30.3 kgce/(m²·a)**、单位采暖建筑面积供暖能耗基准值 **9.2 kgce/(m²·a)**、人均综合能耗基准值 **574.3 kgce/(p·a)**、常规用能系统单位建筑面积电耗基准值 **87.9 kWh/(m²·a)**、引导值 **76.4 kWh/(m²·a)**（省立医院案例引用）。注：这些是官方案例引用的基准值，非标准原文 PDF 直接核验；约束值（更高）仍未拿到全文，报告对标优先用基准值并注明来源口径
- **用水定额 DB37/T 4452-2021（已核验原文）**：二级医院 **通用540 / 先进340 L/(床·d)**（三级440/804、一级296/435）；机关 通用25/先进10 m³/(人·a)。注：医院定额统计范围不含洗衣、制药等，用总取水量对标偏保守，表注说明

### 医院第4项指标：单位开放床日用水量（不是人均取水）

公式：Vz = Wz/(ΣNi×365) × 10³，单位 L/(床·d)；ΣNi 用开放床位数×365 简化。
床位取公开资料（岚山500张），表注注明“按开放床位估算，以院方核定开放床日数为准”。
岚山结果：893.7/834.7/852.8 L/(床·d) vs 通用540 → 超标 55-66%，用水是主要问题点。

### 医院版报告写法差异

- 5.3 指标：非供暖能耗 / 常规电耗 / 人均综合能耗 / **单位开放床日用水量**（+ **单位采暖建筑面积供暖能耗**——DB37/T 2673-2019 表2 有供暖定额，有供暖项目必算）
- 2.1 概况：医院等级（二级甲等）、床位数、职工数、门诊量、青岛大学医疗集团加盟等公开资料
- 2.2 建筑：多栋（门诊病房综合楼/内科病房楼/急诊/影像/后勤）——参数不足时列“建筑地址/功能/面积+【待补充】”
- 5.2.3 用气单独一节（天然气逐年增长 → 提示核查用途构成）
- 7.2 建议侧重：能耗监测（特殊用能分项计量）、**节水改造（水平衡测试/节水器具/冷凝水回收）**、天然气分项计量与管理、空调改造（净化空调运行优化）、照明、光伏、行为节能
- 节能率估算参考：监测0.5-1% / 节水15-25%（用水）/ 天然气5-10% / 空调3-5% / 照明1% / 光伏5-10%

### 数据中心要点（岚山实战）

- **错别字客户陷阱**：同一医院可能存在两个客户记录——“日照市岚山区人民医院”（数据少）与“日照市兰山区人民医院”（错字，地址岚山西路566号，数据全）。判别：地址一致 + 能耗数值交叉一致（2022年电/水完全相同）+ 单价验证。取数据全者，报告用正确单位名，并在交付说明中提示数据源客户记录名
- 旧表 ts_institution_energy（value1..12月度）vs 新表 ts_institution_energy_main：岚山只有旧表有数据（6条：电/水 2022-2024 + 2025电）
- 折标系数列不可信：旧表电系数 0.6472/0.6000/24.0 全是脏值 → 一律用山东标准系数（电0.31/气1.2143）
- 2025年单年数据（电421万kWh）不入审计周期，可在数据说明提及
- 月度异常：2023年1月电量61399kWh 明显异常 → 报告表注【待核实】
- 环境表有测试数据（“222”房间/湿度12%）→ 不用，标注实测待补充
- 费用单位：旧表费用是“万元”直接可用（397.04万），与新版表不同（新版total_value是元）
- 单价验证基准：医院电价≈0.75-0.78元/kWh、水价≈4.1-4.2元/m³、气价≈3.0-3.3元/m³（岚山实测）

### 能源代码（旧表）

01=水、25=天然气、45=电（旧表 energy_name 列“水/天然气/电能”基本可信，但新表 01 曾误标天然气——交叉验证）

### 三级医院案例：山东省立医院东院区（2026-08 实战，奥体院区）

三级甲等综合医院（全省最大医院），与二级医院报告差异：

- **定额对标**：DB37/T 2673-2019 三级医院**基准值已核验**（省局官网案例引用）：非供暖能耗 30.3 kgce/(m²·a)、采暖供暖能耗 9.2、人均综合能耗 574.3 kgce/(p·a)、常规电耗 87.9 kWh/(m²·a)、引导值 76.4 kWh/(m²·a)。省立医院实测（妇幼楼 20549.74m² 单栋口径）235.2 kWh/m² 电耗远超基准——注意**建筑面积口径**：DB 建筑表只录 1 栋楼（妇幼楼）时，单栋面积做分母会使单位面积指标虚高，报告必须注明口径并优先用人均指标评价（实测人均 206.0 kgce/p < 574.3 基准，达标）
- **床位取水对标三级**：通用 804 / 先进 440 L/(床·d)（DB37/T 4452-2021，已核验）——实测 784.0/721.5/741.0（570床）全部低于通用值，评价“低于通用值”；二级医院对标 540/340 则易超标（岚山 55-66% 超标）
- **用能人数与床位**：scene 正式记录 work_staff=3405、bed_num=570；⚠ 3405 与岚山医院填报值完全相同（模板复制迹象），交付时提示用户核实口径
