# 医疗机构（医院）能源审计报告要点（2026-08 日照岚山区人民医院实战）

母版结构同党政机关版（8章+7附录，无发票时6附录），见 `examples/court-agency-audit.md`。本篇记录医院差异点。

## 医院特点（vs 党政机关）

- 全年全天候运行；特殊用能系统：大型医疗设备（CT/MRI）、手术室净化空调、消毒供应蒸汽、洗衣房——定额口径上计入综合能耗、不计入非供暖能耗与常规电耗（独立计量时可剔除）
- 用能人数口径：职工+住院+门诊折算（DB scene.work_staff，岚山=3405人）
- 建筑面积/床位/职工数：DB 常缺（岚山 build 表空）→ 用公开资料并表注“据医院公开资料，以院方核定为准”（岚山：43000m²、500床、806职工）
- 能耗品种常只有电/水/天然气（岚山无热力/油记录；天然气用途消毒/食堂/供暖未分项）

## 定额标准

- **DB37/T 2673-2019《医疗机构能源消耗定额标准》**（鲁事管办发〔2021〕54号确认医院按此执行）：二级医院具体数值（非供暖能耗/电耗/人均综合能耗约束-基准-引导）网上无免费全文——**拿不到就按技能原则用【待核验】占位并显式提示用户**，不编造。**三级医院基准值已核验**（2026-08 省机关事务管理局官网绿色低碳公共机构案例引用，淄博市妇幼保健院申报文）：单位建筑面积非供暖能耗基准值 **30.3 kgce/(m²·a)**、单位采暖建筑面积供暖能耗基准值 **9.2 kgce/(m²·a)**、人均综合能耗基准值 **574.3 kgce/(p·a)**、常规用能系统单位建筑面积电耗基准值 **87.9 kWh/(m²·a)**、引导值 **76.4 kWh/(m²·a)**（省立医院案例引用）。注：这些是官方案例引用的基准值，非标准原文 PDF 直接核验；约束值（更高）仍未拿到全文，报告对标优先用基准值并注明来源口径
- **用水定额 DB37/T 4452-2021（已核验原文）**：二级医院 **通用540 / 先进340 L/(床·d)**（三级440/804、一级296/435）；机关 通用25/先进10 m³/(人·a)。注：医院定额统计范围不含洗衣、制药等，用总取水量对标偏保守，表注说明

## 医院第4项指标：单位开放床日用水量（不是人均取水）

公式：Vz = Wz/(ΣNi×365) × 10³，单位 L/(床·d)；ΣNi 用开放床位数×365 简化。
床位取公开资料（岚山500张），表注注明“按开放床位估算，以院方核定开放床日数为准”。
岚山结果：893.7/834.7/852.8 L/(床·d) vs 通用540 → 超标 55-66%，用水是主要问题点。

## 医院版报告写法差异

- 5.3 指标：非供暖能耗 / 常规电耗 / 人均综合能耗 / **单位开放床日用水量**（+ **单位采暖建筑面积供暖能耗**——DB37/T 2673-2019 表2 有供暖定额，有供暖项目必算）
- 2.1 概况：医院等级（二级甲等）、床位数、职工数、门诊量、青岛大学医疗集团加盟等公开资料
- 2.2 建筑：多栋（门诊病房综合楼/内科病房楼/急诊/影像/后勤）——参数不足时列“建筑地址/功能/面积+【待补充】”
- 5.2.3 用气单独一节（天然气逐年增长 → 提示核查用途构成）
- 7.2 建议侧重：能耗监测（特殊用能分项计量）、**节水改造（水平衡测试/节水器具/冷凝水回收）**、天然气分项计量与管理、空调改造（净化空调运行优化）、照明、光伏、行为节能
- 节能率估算参考：监测0.5-1% / 节水15-25%（用水）/ 天然气5-10% / 空调3-5% / 照明1% / 光伏5-10%

## 数据中心要点（岚山实战）

- **错别字客户陷阱**：同一医院可能存在两个客户记录——“日照市岚山区人民医院”（数据少）与“日照市兰山区人民医院”（错字，地址岚山西路566号，数据全）。判别：地址一致 + 能耗数值交叉一致（2022年电/水完全相同）+ 单价验证。取数据全者，报告用正确单位名，并在交付说明中提示数据源客户记录名
- 旧表 ts_institution_energy（value1..12月度）vs 新表 ts_institution_energy_main：岚山只有旧表有数据（6条：电/水 2022-2024 + 2025电）
- 折标系数列不可信：旧表电系数 0.6472/0.6000/24.0 全是脏值 → 一律用山东标准系数（电0.31/气1.2143）
- 2025年单年数据（电421万kWh）不入审计周期，可在数据说明提及
- 月度异常：2023年1月电量61399kWh 明显异常 → 报告表注【待核实】
- 环境表有测试数据（“222”房间/湿度12%）→ 不用，标注实测待补充
- 费用单位：旧表费用是“万元”直接可用（397.04万），与新版表不同（新版total_value是元）
- 单价验证基准：医院电价≈0.75-0.78元/kWh、水价≈4.1-4.2元/m³、气价≈3.0-3.3元/m³（岚山实测）

## 三级医院案例：山东省立医院东院区（2026-08 实战，奥体院区）

三级甲等综合医院（全省最大医院），与二级医院报告差异：

- **定额对标**：DB37/T 2673-2019 三级医院**基准值已核验**（省局官网案例引用）：非供暖能耗 30.3 kgce/(m²·a)、采暖供暖能耗 9.2、人均综合能耗 574.3 kgce/(p·a)、常规电耗 87.9 kWh/(m²·a)、引导值 76.4 kWh/(m²·a)。省立医院实测（妇幼楼 20549.74m² 单栋口径）235.2 kWh/m² 电耗远超基准——注意**建筑面积口径**：DB 建筑表只录 1 栋楼（妇幼楼）时，单栋面积做分母会使单位面积指标虚高，报告必须注明口径并优先用人均指标评价（实测人均 206.0 kgce/p < 574.3 基准，达标）
- **床位取水对标三级**：通用 804 / 先进 440 L/(床·d)（DB37/T 4452-2021，已核验）——实测 784.0/721.5/741.0（570床）全部低于通用值，评价“低于通用值”；二级医院对标 540/340 则易超标（岚山 55-66% 超标）
- **用能人数与床位**：scene 正式记录 work_staff=3405、bed_num=570；⚠ 3405 与岚山医院填报值完全相同（模板复制迹象），交付时提示用户核实口径
- **供热验证选记录**：scene 有两组矛盾记录（正式：54523.3m²×22元=119.95万；草稿：45000m²×34.5元=155.25万）——用费用反推：热费 119.95万 与正式组精确吻合 → 取正式组；判别方法：缴费面积×单价=年热费
- **energy_main 新表可能是复制测试数据**：省立 energy_main 31条全是 is_draft=1，数值与岚山医院完全相同（电 5090273/5225773/4833915、水 163107.7/150110/154167、气 57207/68483/79374、热费 1200000.00 元整数×3年）→ 弃用，真实数据在旧表 ts_institution_energy。判别特征：**多客户数值完全相同 + 费用为整数 = 模板复制测试数据**
- **历史导出 data.json 也可能是测试包**：`projects/energy-audit/<单位>/data.json` 中 buildings=妇幼楼（岚山地址）、people=300、beds=0 → 盲信历史文件会错；交叉验证地址/数值与 DB 一致性
- **环境实测筛选**：ts_institution_environment 混真假数据——取 deleted=0 且 room_name 合理（剔除“治疗室测试”“房间2”、数值全 33 的假记录）；省立有 2024-05-07 九点位真实实测（治疗室/检查室/诊室/候诊室/挂号厅/病房/走廊/护士站/药房）→ 写入 6.5 节+附录4；照度按 GB/T 50034 医院分房间标准评价（治疗室/诊室 300、候诊室/挂号厅 200、病房 100、走廊 50、护士站/药房 300）；PM2.5 实测 50-100μg/m³ 接近限值→建议关注
- **计量**：电表 18 块分科室（sub_metering='1,2,4,3'）、水仅总表（measured_depth='仅总表'）→ 报告 4.2 节如实写“电计量完善、水计量不足”
- **节能改造史**：LED 平板灯 2023 年由荧光灯改造、走廊吸顶灯 2024-05 感应改造、节水器具更换、获评节约型公共机构——写入 3.3 成效与 7.1/7.2
- 济南采暖期：《济南市城市集中供热管理条例》11月15日—次年3月15日（供热面积 54523.3m²、22元/m²、年费 119.95万）
- 设备表真实数据可用：YORK YSEZEZS45CKE/22 冷水机组 298kW×2（2020）、燃气蒸汽锅炉×3（2023，手术室）、冷却塔、水泵 3级能效
- 油口径：汽油 10.86t+柴油 20.21t（2024）单独统计不计入综合能耗（技能口径）；费用表不含油，表注说明
- 建筑面积 67636m²（7栋楼，用户确认），供热面积 54523.3m² 与之不同属正常（部分区域不供暖）
