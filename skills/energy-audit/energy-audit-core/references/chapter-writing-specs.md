# 各章写作规范

## 第2章 公共机构基本情况

### 2.1 公共机构基本情况

**写作方式**：LLM 生成自然段落，不应使用模板填充。

**必须覆盖的关键要素**（一段式）：单位全称 → 简称 → 行政归属 → 地址 → 内设机构/科室 → 人员编制 → 建筑数量及名称 → 代表性建筑面积 → 竣工年代特征。

**示例**：
> 莘县县政府（以下简称"莘县政府"）是莘县人民政府直属国家机关，位于莘县政府街003号。院内共设有办公室、发改局、财政局等20余个内设机构，现有在职职工约300人。总建筑面积4190平方米，主要建筑物包括南楼和北楼2栋：其中南楼建成于1989年，地上5层；北楼建成于2019年，地上2层。两栋建筑均采用框架结构，设有外墙保温。

**照片**：仅插入建筑外观照片，不插入室内设备照片（照明、空调、水泵等设备照片留给第6章用）。

### 2.2 建筑物概况

**结构**：两段式 + 建筑参数表。

**段1（总览 + 共性特征）**：
- 建筑名称列表
- 共性特征（结构形式、外保温、外窗类型等）

**段2（逐栋详情）**：
- 每栋一句：竣工年代 + 层数 + 结构

**收口**："各建筑详细参数见表2-1至表2-N。"

**建筑参数表**：4列键值对格式，标题在表格上方（不合并到表格内）。
包含字段：建筑物名称、建筑地址、建造年代、建筑功能、建筑层数及朝向、建筑面积、建筑功能分区、建筑结构形式、建筑外窗类型、建筑外墙保温、夏季空调冷源、冬季供暖热源、夏季空调末端形式、冬季供暖末端形式、建筑给水系统、建筑消防给水系统、生活热水系统、能耗在线监测系统。

### 2.3 能源资源利用情况

**结构**：按用能类型动态生成——电系统一段、水系统一段、气系统一段（有该类型才写，没有跳过）。

## 第5章 能源资源消费/消耗指标分析

### 5.1 能源资源消费/消耗概况
- **一句话开头**："XXX主要用能类型包括电、天然气、水。"（不写长篇综述）
- **能源流向图**：graphviz 生成，三层结构（能源→用能系统→终端设备），实线/虚线路由
- **无**：饼图、趋势图、能源结构表、逐年对比表（都不在5.1）

### 5.2 能源资源消耗/消费数据

**动态H3小节**：主要能源独立小节（折标能耗占比≥5%或水，固定顺序 电→水→气→热→油），
次要能源并入"其他用能分析"小节。有数据才生成。

**每小节结构**（四个步骤）：
1. **段1（设备描述 + 三年具体数值 + 图引用）**：
   - 用电类型：枚举主要用电设备（空调、照明、办公等）
   - 用水类型："用水系统主要为生活用水、卫生清洁用水等"
   - 用气类型："用气系统主要为厨房炉灶设备用气"
   - 然后："根据能耗账单及缴费发票统计分析，XXX2022年全年XX量为XXXkWh，2023年全年XX量为XXXkWh，2024年全年XX量为XXXkWh。变化趋势如图5.X所示。"

2. **逐年总量柱状图（matplotlib bar chart）**
   - 图题："图5.X  XXXX年-XXXX年总XX量（单位：XX）"

3. **段2（逐年分析）**：
   - "由图5.X分析，XXX整体波动不大/呈逐年增长/下降趋势。"
   - 逐年同比变化："其中2023年同比增长X%，2024年同比下降X%。"

4. **逐月分组柱状图（matplotlib grouped bar chart）**：
   - 图题："图5.X+1  XXXX年-XXXX年逐月XX量（单位：XX）"（独立编号全章连号）
   - 仅在月度数据存在时生成（无月度数据不画图，如市政供暖热力）

5. **逐月分析**：
   - "从逐月XX量来看，夏季明显高于冬季/各月分布均匀/冬季明显高于夏季"
   - "最高月份为X月（XXkWh），最低月份为X月（XXkWh）。"

**重要**：5.2 不包含数据表格。

### 5.2.N+1 能源资源费用分析
- 表5.1 各项能源费用统计表 + 各年能源费用占比饼图（每年一张、连号）

### 5.3/5.4 指标与基准
- 表号：表5.1=费用统计表；5.3 指标表从表5.2 起连号；5.4 两张基准表顺延
- H3标题：宋体12pt加粗

## 第6章 主要能源资源利用系统分析

### 6.1 用电系统运行分析

**总述段落**：不写具体数字，只列出有哪些系统类别。
> "XXX用电系统主要包括空调与供暖系统、照明系统、办公设备系统等。"

**分系统H3标题**（按顺序生成）：
1. 空调与供暖系统
2. 照明系统
3. 办公设备系统
4. 其他用电设备
5. 变配电系统
6. 信息机房系统

**每个分系统的写作模式**（有设备时）：
1. **设备描述段落**：具体设备名称 + 各多少台 + 功能用途 + 运行时间/季节
2. **⚠️ 节能改造提示**："⚠️ 请提供XXX的节能改造情况：是否进行过节能改造、改造措施及效果。"（如无信息）
3. **📷 照片**：设备照片，嵌入文档
4. **设备清单表**："表6.1-N  XXX清单"（4列：序号/名称/规格/数量/备注）

**无设备的分系统（变配电/信息机房）**：
- 仅⚠️提示段落，说明需要提供的信息

### 6.N 其他系统
6.2用水、6.3供暖等按原逻辑动态生成。

## 月度数据

月度数据支持字段（可选，有则生成逐月柱状图，无则跳过）：
- `monthly_electricity_kwh`: [12个月的用电量]
- `monthly_water_m3`: [12个月的用水量]
- `monthly_natural_gas_m3`: [12个月的用气量]

**三处同步**：添加新字段时需同时更新：
1. `EnergyYearly` dataclass（project_data.py）
2. config JSON 的 `energy_yearly` 数组
3. 数据加载构造（`pg_collector.py::_collect_from_pg_impl` / `project_data.py` 持久化读取）
