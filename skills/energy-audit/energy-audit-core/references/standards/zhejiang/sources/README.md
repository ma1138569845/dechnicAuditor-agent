## 四、引用纪律

1. 报告引用时写“标准号 + 表号/条款号”，不写“来源：DB33”这种无锚点表述；
2. 表4 的“单位面积电耗”与表2 的“单位面积能耗”数值相同，引用时按表4 表号，不自行改数；
3. 760 表1 的三列是 3级/2级/1级，不写成约束/基准/引导；
4. 736 的机构层级/场馆类型、760 的星级/建设性质，必须在报告中写明后再取行/列。
