# 浙江 × 公共机构标准包

## 加载顺序

1. 本目录 `quota-values.json`：737、738 和公共机构扩充口径。
2. `../quota-values.json`：736 行政机关/场馆的唯一共享数值源。
3. `calculation-spec.md`：子类、计算和拒绝规则。
4. `coefficients.md`：折标系数。
5. `sources.json`：官方原文地址与本地 PDF。

## 为什么不复制 736

浙江公共建筑与浙江公共机构都会使用 DB33/T 736。复制两份定额表会让一次修订产生两种结果。公共建筑包继续保存 736 的共享权威数据，公共机构包通过显式共享引用组合读取，测试会校验共享值能正常加载。

## 硬边界

- 只有“公共机构 + 浙江”进入本包。
- 一级医疗机构不适用 DB33/T 738；成人高校、自考高校不适用 DB33/T 737。
- 不支持的子类必须终止，不得借用山东 DB37/T 2671、2672、2673 或浙江公共建筑 DB33/T 760。
- 第 5 章使用三档评价，不输出“先进值”代替“基准值/引导值”。
