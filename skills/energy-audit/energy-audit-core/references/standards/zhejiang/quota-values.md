## 一、DB33/T 736-2021《行政机关、场馆能耗定额及计算方法》

### 1.1 适用范围与维度

- 行政机关：按 **省级 / 市级 / 县级及以下** 分档；
- 场馆：按 **科技馆 / 文化馆 / 博物馆** 分档；
- 指标分两类：
  - **主要指标**：单位建筑面积能耗、人均综合能耗；
  - **参考指标**：常规用能系统单位建筑面积电耗、人均电耗、数据中心机房 EEUE。

> 样本（长三院 AB/CD）使用的是**市级**行；其他项目必须按实际层级取行，不得默认市级。

### 1.6 统计范围（第5章，PDF 第9~10页）

| 项 | 规则 |
|---|---|
| 综合能耗 | 独立核算且可分项计量的食堂、浴室、健身等非办公用能不计入；可分项计量的特殊用能区域（数据中心、中心控制室、信息中心、监控中心、档案室、演播中心、服务大厅等）不计入 |
| 建筑能耗 | 除交通工具用能外；可分项计量的特殊用能区域不计入 |
| 总电耗 | 空调、动力、照明、插座等常规用能系统；独立核算且可分项计量的食堂、浴室、健身不计入；可分项计量的特殊用能区域不计入 |
| 建筑面积 | 证载建筑面积（职工住宅除外）；未计入能源统计范围的区域，其面积同步剔除 |
| 用能人数 | 全天办公人员：在编 + 签订一年以上劳务合同的非在编 + 提供全天服务人员；临时进场/参会人员不计入 |

> 关键：**"剔除"以"可分项计量"为前提**；没有分项计量就无法剔除，必须在报告中说明。

### 1.7 修正系数（6.3，PDF 第12页）

> 行政机关或场馆办公建筑为 **2005 年以前投入使用，且没有安装中央空调** 的，综合能耗/建筑能耗/电耗修正系数为 **1.2**；统计期内的综合能耗或电耗乘以 1.2 后，再计算单位建筑面积能耗、人均综合能耗、常规电耗、人均电耗。

## 二、DB33/T 760-2023《旅游饭店单位综合能耗限额及计算方法》

### 2.1 表1 单位可比综合能耗限额（PDF 第6页）

| 饭店类型 | 3级（既有饭店限额值） | 2级（新建/改建约束值） | 1级（先进值） |
|---|---|---|---|
| 按五星级标准设计、建设 | ≤33 | ≤23 | ≤18 |
| 按四星级标准设计、建设 | ≤28 | ≤20 | ≤15 |
| 按三星级及以下标准设计、建设 | ≤25 | ≤18 | ≤12 |

单位：kgce/m²。

规则：

- **既有饭店**对标 3 级（限额值）；
- **新建/改建饭店**对标 2 级（约束值）；
- 1 级为先进值；
- 不得把三列简单写成"约束/基准/引导"。

### 2.2 综合能耗统计范围（5.1，PDF 第6~7页）

- 统计经营服务过程中实际消耗的各类能源，含一次能源、二次能源及耗能工质（新水、地下水、温泉水）；
- **不包括员工生活和其它作业用能**；
- 室外庭院照明、停车场照明、立面照明、霓虹灯、广告牌等电耗应计入；
- 独立计量的公共亮灯工程、公共充电桩等非饭店经营用电可不计入；
- 出租商场、商铺的能耗和建筑面积应计入。

### 2.3 建筑面积（5.1.2 / 5.2.1，PDF 第7页）

```
Mm = M − (Cm × N)
```

- `M`：总建筑面积（GB/T 50353，取得产权/测绘证明）；
- `Cm`：地下室每个停车位按 30 m²；
- `N`：地下室停车位数量；
- 地下人防区域（产权不列入）不计入；
- 出租商场/商铺面积计入。

### 2.4 单位可比综合能耗（5.2.4，PDF 第7页）

```
Ekd = Ej / (a1 × a2 × … × am)
```

- `Ej`：单位综合能耗（综合能耗 ÷ Mm）；
- `a`：各项修正系数；
- **修正系数连乘后作除数**，不是乘数。

### 2.5 修正系数（5.3，PDF 第8页）

| 修正项 | 条件 | 系数 |
|---|---|---|
| 洗衣房 | 含水洗、干洗、熨烫 | 1.10 |
| 恒温游泳池/水池 | V=200 m³ | 1.02；V>200 m³ 每增 10% 递增 0.01，最高 1.10 |
| 热力管网供热 | 采用热力管网 | 0.90 |
| 建筑容积率 R | R≤0.55 | 1.20 |
|  | 0.55<R≤0.80 | 1.10 |
|  | R>0.80 | 不作修正 |
| 餐饮、会议面积比 S | S<30% | 不作修正 |
|  | 30%≤S≤40% | 1.10 |
|  | 40%<S≤50% | 1.20 |
|  | S>50% | 1.30 |
| 客房出租率 Q | Q≤35% | 0.91 |
|  | 35%<Q≤45% | 0.94 |
|  | 45%<Q≤55% | 0.97 |
|  | 55%<Q≤65% | 1.00 |
|  | 65%<Q≤75% | 1.03 |
|  | 75%<Q≤85% | 1.06 |
|  | Q>85% | 1.10 |

> 样本只用了 1.10（出租率>85%），未说明是否还有洗衣房、泳池、热力管网、容积率、餐饮会议比等修正项；模板要求逐项判断并列出。

## 四、取数维度清单

办公/场馆项目必须先确认：

- 机构层级：省级 / 市级 / 县级及以下（行政机关）；
- 场馆类型：科技馆 / 文化馆 / 博物馆；
- 是否有食堂；
- 建筑投用年份与是否中央空调（1.2 修正）；
- 特殊用能/食堂/浴室/健身是否可分项计量。

公寓/饭店项目必须先确认：

- 饭店星级：五星 / 四星 / 三星及以下；
- 既有 / 新建改建（3级 / 2级）；
- 洗衣房、恒温泳池、热力管网、容积率、餐饮会议面积比、出租率；
- 床位数、入住率；
- 建筑面积（扣除地下车位、人防）。
