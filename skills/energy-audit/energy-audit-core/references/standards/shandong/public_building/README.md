# 山东 × 公共建筑标准包

## 加载顺序

1. `quota-values.json`：代码唯一数值入口。
2. `calculation-spec.md`：计算和拒绝规则。
3. `coefficients.md`：折标口径。
4. `sources.json`：官方来源、下载地址与校验信息。
5. `quota-values.md`：人工阅读和审核索引。

## 子类路由

| 平台码 | 建筑子类 | standard_id | 状态 |
|---|---|---|---|
| `A` + `A1/A2/A3` | 宾馆酒店（五/四/三星级） | `DB37/T 5076-2024` | 现行 |
| `B` | 机关办公 | `DB37/T 5077-2016` | 2024-10-09 废止；受控过渡 |
| `C` | 商务办公 | `DB37/T 5078-2024` | 现行 |
| `D` + `D1/D2/D3/D4` | 三级/二级及以下综合或专科医院 | `DB37/T 5079-2024` | 现行 |

山东公共建筑从 `public_build_type` / `public_build_type_A` /
`public_build_type_D` 读取上述平台码。`A`、`D` 必须同时提供有效二级码，
`B`、`C` 的二级码必须为空。缺少码、码不匹配或跨字典解释时停止计算，
不得按单位名称猜测，也不得默认成商务办公或三星级酒店。

`DB37/T 5077-2016` 仅用于山东公共建筑 `B=机关办公` 的受控过渡兼容。
该标准当前没有已接入的现行替代标准，使用结果是过渡性结论；报告依据
章节必须披露“已于 2024-10-09 废止”。禁止把 5077 用于浙江、公共机构、
宾馆酒店、商务办公或医院，也禁止用 5076/5078/5079 代替 5077。
