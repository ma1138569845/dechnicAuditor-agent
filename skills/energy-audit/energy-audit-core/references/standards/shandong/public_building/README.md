# 山东 × 公共建筑标准包

## 加载顺序

1. `quota-values.json`：代码唯一数值入口。
2. `calculation-spec.md`：计算和拒绝规则。
3. `coefficients.md`：折标口径。
4. `sources.json`：官方来源、下载地址与校验信息。
5. `quota-values.md`：人工阅读和审核索引。

## 子类路由

| 项目信息 | standard_id |
|---|---|
| 宾馆、酒店、饭店、旅馆 | `DB37/T 5076-2024` |
| 商务办公、写字楼、商务楼 | `DB37/T 5078-2024` |
| 医院、医疗机构 | `DB37/T 5079-2024` |
| 机关办公、党政机关办公 | 拒绝：DB37/T 5077-2016 已废止 |

不要把建筑功能只写在正文里而不进入机器字段。项目必须提供可判断的类别；不能判断时返回明确错误，禁止默认套用商务办公。
