## 二、选择键

```
province（山东 / 浙江 / …）
  × audit_type（公共机构 / 公共建筑 / 工业企业）
  × building_subtype（办公 / 场馆 / 公寓 / 饭店 / 园区）
```

规则：

1. `audit_type` 优先于"建筑功能"：医院、学校既可能是公共机构，也可能是公共建筑，按项目登记的 `audit_type` 选包。
2. 标准包未核验时，报告中的定额值必须标【待核验】，不得写成正式依据。
3. 不得把山东 `standards-values.md` 的数值复制到浙江包，也不得把浙江值写回山东表。
4. 新增标准包时必须在本表登记；未登记的标准包视为草稿。

## 三、与现有权威索引的关系
