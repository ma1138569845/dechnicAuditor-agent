# 三遍提取输出 Schema

每遍提取的固定输出格式。三遍必须分开执行，禁止合并成一次"总结全文"。
所有模板中的 `{}` 为占位符；输出中不得出现样板报告的专名、数值、年月。

---

## Pass 1：结构树

```
## 结构树
- 第X章 <章名>
  - 目的：<该章回答什么问题/承担什么任务，一句话>
  - X.Y <节名>
    - 目的：<该节功能，一句话>
    - （递归到小节）

## 与权威结构的偏差
| 章/节 | energy-audit-core 权威 | 本样板实际 | 偏差原因（机构类型差异/标准要求/样板特色） |
|---|---|---|---|
```

要点：

- "目的"写功能（如"汇总三年能耗并给出总量/结构/趋势"），不写内容转述。
- 偏差表只记差异；与权威一致的章节不重复抄一遍。
- 样板章节号与权威不同（如 0-11 章市州版 vs 8 章版）时，在偏差表标注"市州模板
  骨架，见 energy-audit-report/references/city-template-guide.md"，不展开。

## Pass 2：论证链

每节一条，格式：

```
- 节：<节名>
  - 输入：<写本节需要哪些数据/事实；用数据字段语义，不用数值>
  - 推理：
    1. <动作：calculate / compare / identify / explain / cite>
       <做什么：算哪个指标、与哪个基准比、识别哪种异常、解释什么原因、引用哪条标准>
    2. ...
  - 输出：<结论句要素 / 表格 / 图 / 评价短语>
  - 触发：<什么条件下写本节；数据缺失时如何处理（跳过/占位/【待补充】）>
```

动作动词固定用：calculate / compare / identify / explain / cite / propose。
禁止在"推理"里写"第X年增加了Y%"，一律泛化为"{年份}较{上一年}增加{Δ}，增加率为{增长率}"这类骨架。

## Pass 3：语言风格

```
## 句法模式
- name: <模式名>
  - trigger: <什么场景使用>
  - template: <句式骨架，{...}占位>
  - example: <泛化示例，无事实>

## 占位体系（语义区分）
- 【待补充】=<含义与使用场景>
- 【待核验】=<含义与使用场景>
- 【待核实】=<含义与使用场景>

## 禁词/禁用句式
- <词/句式> —— <原因>

## 评价短语（固定词表，禁加括号后缀）
- <短语> = <判定条件>
```

要点：

- 评价短语必须与既有口径对齐（低于约束值/低于基准值/高于约束值/高于通用值等，
  纯短语无括号后缀），样板中若有不同写法，记录为"样板写法"供比对，不改动既定口径。
- template 必须能从样板句抽象出来且换数据可用；抽象不出来的不写。
- example 中如果出现样板单位名/数值，即泛化失败，重做。
