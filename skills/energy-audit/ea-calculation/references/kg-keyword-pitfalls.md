# KG关键词匹配规范与踩坑

## 核心规则

**因果链的 `anomaly_keywords` 只能使用领域专有词，严禁泛化词。**

### 禁止的关键词类型

| 类型 | 禁止词例 | 原因 |
|------|---------|------|
| 方向/程度 | "偏高""偏低""增加""大幅""下降""异常" | 多个系统共用，100%跨系统误匹配 |
| 通用动词 | "运行""使用""消耗" | 无区分度 |
| 通用形容词 | "大""小""多""少""高""低" | 太短，命中率虚高 |

### 允许的关键词类型

| 类型 | 例 | 原因 |
|------|---|------|
| 设备名 | "冷机""水泵""冷却塔""变压器""电梯" | 唯一匹配 |
| 系统名 | "照明""供暖""给排水""机房" | 唯一匹配 |
| 专业参数 | "COP""PUE""功率因数""负载率" | 领域特指 |
| 专业缩略语 | "BAS""LED""UPS""CT""MRI" | 高精度 |
| 专业现象 | "水力失衡""近热远冷""大马拉小车" | 多字组合，精确 |

## 实际案例

### 案例1："功率因数0.75偏低" 误匹配 "冷机COP偏低"

- 原因："偏低"是两者共有关键词，且COP链排前面
- 修复：从COP链关键词中删除"偏低""下降"，仅保留"COP""cop""能效""制冷效率""冷机效率"

### 案例2："供水系统压力偏高" 误匹配 "水泵效率偏低"

- 原因："偏低"是泛化词
- 修复：从所有链的keywords中删除"偏低""偏高""增加""大幅""下降"

### 案例3："电梯能耗偏高" 误匹配 "冬季电耗偏高"

- 原因："偏高"是泛化词
- 修复：冬季电耗链只保留"冬季""电耗""电辅热""热泵""低温"

## 验收标准

新增因果链后，必须用至少3个**易混淆场景**验证：
1. 不同系统但共享泛化词 → 应各自匹配到正确系统
2. 同系统不同异常 → 应区分精确
3. 无匹配词的异常 → 应有语义兜底（v3.0混合匹配）

执行：`python -c "from tools.energy_audit.energy_kg import create_default_kg; kg = create_default_kg(); ..."`
