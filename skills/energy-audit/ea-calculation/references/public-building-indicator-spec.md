# 浙江公共建筑指标规范（v0.2，已核验）

> 适用：浙江省公共建筑能源审计（办公/场馆/公寓/饭店）
> 依据：DB33/T 736-2021、DB33/T 760-2023、浙江省用（取）水定额（2019）
> 核验：2026-10-20 与三份标准原文逐表核对
> 关键口径：电力 **0.1229 kgce/kWh（当量值）**；饭店新水 **0.2571 kgce/t**

## 一、与山东公共机构线的差异（先看这一节）

| 项 | 山东公共机构 | 浙江公共建筑 |
|---|---|---|
| 电力折标 | 0.31（等价值） | **0.1229（当量值）** |
| 单位面积能耗 | 扣供暖、扣特殊用能、扣车库 | 736：扣交通 + **可分项计量的**特殊/食堂/浴室/健身；没有分项计量无法扣 |
| 单位面积电耗 | (总电 − 供暖电) ÷ 面积 | 736：总电（按 5.3 范围）÷ 面积，**不扣供暖电量** |
| 指标数 | 5 项（含非供暖能耗、供暖能耗） | 办公/场馆 5 项；饭店 3 项 |
| 人均电耗 | 无 | **有**（736 参考指标） |
| 饭店新水 | 不折算 | **0.2571 kgce/t 计入综合能耗** |

> 结论：**不能复用山东的 `indicators.py` 公式链**；本文件是独立口径。

## 二、公共基础

### 2.1 建筑能耗（736）

```
Ej = Σ(ej × pj)
```

- `ej`：第 j 种能源实物量；
- `pj`：折标系数；
- 统计范围：除交通工具用能外的建筑使用能耗；
- 可分项计量的特殊用能区域（数据中心、中心控制室、信息中心、监控中心、档案室、演播中心、服务大厅等）不计入；
- 独立核算且可分项计量的食堂、浴室、健身不计入综合能耗/总电耗。

### 2.2 综合能耗（736/760）

- 736：统计范围内各类能源折标之和，扣除可分项计量的特殊/食堂/浴室/健身；
- 760：经营服务过程中实际消耗的各类能源，含新水等耗能工质；**不含员工生活和其它作业用能**。

### 2.3 折标系数

| 能源 | 系数 | 单位 | 适用 |
|---|---|---|---|
| 电力 | **0.1229** | kgce/kWh（当量） | 736 / 760 |
| 天然气 | 1.2143 | kgce/m³ | 736 / 760 |
| 汽油 | 1.4714 | kgce/kg | 736 / 760 |
| 柴油 | 1.4571 | kgce/kg | 736 / 760 |
| 热力 | **0.03412** | kgce/MJ（当量） | 736 / 760 |
| 新水（自来水） | **0.2571** | kgce/t | **仅 760 饭店综合能耗** |

> 736 附录 A 无新水系数；不要给办公/场馆加新水。

### 2.4 评价语义

**736**：约束值 / 基准值 / 引导值，三档。

**760**：

- 3 级 = 既有饭店限额值；
- 2 级 = 新建/改建饭店约束值；
- 1 级 = 先进值；
- 不得写成"约束/基准/引导"。

**用水定额**：先进值 / 通用值，两档。

## 三、办公/场馆类（DB33/T 736-2021）

### 3.1 先确认维度

| 维度 | 取值 | 影响 |
|---|---|---|
| 机构层级（行政机关） | 省级 / 市级 / 县级及以下 | 表1、表3 取行 |
| 场馆类型 | 科技馆 / 文化馆 / 博物馆 | 表2、表4 取行 |
| 是否有食堂 | 有 / 无 | 用水定额取行 |
| 投用年份 + 是否中央空调 | 2005 年前且无中央空调 → ×1.2 | 四项指标修正 |
| 特殊/食堂/浴室/健身是否可分项计量 | 是 / 否 | 是否剔除 |

> 样本长三院 AB/CD 用的是**市级**行；其他项目不得默认市级。

### 3.2 五项指标

| 节号 | 指标 | 类型 | 公式 | 单位 |
|---|---|---|---|---|
| 5.3.1 | 单位建筑面积能耗 | 主要 | 建筑能耗 Ej ÷ 建筑面积 S | kgce/m² |
| 5.3.2 | 常规用能系统单位建筑面积电耗 | 参考 | 总电耗 Ed ÷ 建筑面积 S | kWh/m² |
| 5.3.3 | 人均综合能耗 | 主要 | 综合能耗 Ez ÷ 用能人数 P | kgce/per |
| 5.3.4 | 人均电耗 | 参考 | 总电耗 Ed ÷ 用能人数 P | kWh/per |
| 5.3.5 | 单位用水量 | 用水定额 | 年取水量 Vk ÷ 人数 Np | m³/(p·a) |

规则：

- 5.3.1 / 5.3.3 是**主要指标**，5.3.2 / 5.3.4 是**参考指标**，报告中应注明；
- 5.3.5 不是 736 的能耗指标，按浙江省用水定额单独对标；
- 数据中心机房可另列 EEUE（参考指标 2.0/1.8/1.5），无数据中心不写。

### 3.3 统计范围与剔除

| 项 | 规则 |
|---|---|
| 建筑能耗 | 除交通工具外；可分项计量的特殊用能区域不计入 |
| 综合能耗 | 同上；独立核算且可分项计量的食堂、浴室、健身不计入 |
| 总电耗 | 空调、动力、照明、插座；独立核算且可分项计量的食堂、浴室、健身、特殊用能区域不计入 |
| 建筑面积 | 证载面积（职工住宅除外）；未纳入能源统计范围的区域，面积同步剔除 |
| 用能人数 | 在编 + 一年以上合同非在编 + 全天服务人员；临时/参会不计入 |

> 没有分项计量 → 无法剔除 → 报告中写明"未单独计量，未剔除"，不得假装剔除。

### 3.4 1.2 修正（736 §6.3）

适用条件（同时满足）：

1. 办公建筑；
2. 2005 年以前投入使用；
3. 没有安装中央空调。

修正方式：

- 综合能耗 ×1.2；建筑能耗 ×1.2；电耗 ×1.2；
- 再用修正后的值计算 5.3.1~5.3.4。

报告中必须写"按 DB33/T 736-2021 §6.3 修正系数 1.2"。

## 四、公寓/饭店类（DB33/T 760-2023）

### 4.1 先确认维度

| 维度 | 取值 | 影响 |
|---|---|---|
| 饭店星级 | 五星 / 四星 / 三星及以下 | 表1 取行 |
| 既有 / 新建改建 | 3级 / 2级 | 对标列 |
| 洗衣房 | 有 / 无 | ×1.10 |
| 恒温泳池/水池 | 容积 V | 1.02~1.10 |
| 热力管网 | 有 / 无 | ×0.90 |
| 容积率 R | 数值 | 1.20 / 1.10 / 无 |
| 餐饮会议面积比 S | 数值 | 无 / 1.10 / 1.20 / 1.30 |
| 客房出租率 Q | 数值 | 0.91~1.10 |
| 床位数、入住率 | 数值 | 水耗对标 |

### 4.2 三项指标

| 节号 | 指标 | 类型 | 公式 | 单位 |
|---|---|---|---|---|
| 5.3.1 | 单位综合能耗 | 参考 | 综合能耗 E ÷ 建筑面积统计值 Mm | kgce/m² |
| 5.3.2 | 单位可比综合能耗 | 主要 | 单位综合能耗 Ej ÷ (a1×a2×…×am) | kgce/m² |
| 5.3.3 | 单位用水量 | 用水定额 | 年取水量 ÷ 床位数 | m³/(床·年) |

> 760 没有"常规用能系统单位建筑面积电耗"这一指标。样本列了该项，只能作为**额外参考**，不得对标 736 的 70/45/25。

### 4.3 综合能耗与建筑面积

```
E = Σ(ei × pi)         # 含新水 0.2571 kgce/t
Mm = M − (30 × N)      # 总建筑面积 − 地下车位面积
Ej = E / Mm
Ekd = Ej / (a1×a2×…×am)
```

- `M`：总建筑面积（产权/测绘）；
- `N`：地下室停车位数量；
- 地下人防区域不计入；
- 出租商场/商铺面积计入。

### 4.4 修正系数

按 `quota-values.md` §2.5 逐项判断；**连乘后作除数**。

常见错误：

- 只写"出租率修正 1.10"，不列其他修正项；
- 把 1.10 当乘数；
- 把 3级/2级/1级写成约束/基准/引导；
- 综合能耗只算电，漏掉新水。

## 五、常见错误

1. 用 0.31 代替 0.1229；
2. 套山东公式扣供暖电量；
3. 736 默认用市级行，不确认机构层级；
4. 场馆套行政机关的定额；
5. 特殊/食堂/浴室/健身没有分项计量却"假装剔除"；
6. 漏掉 2005 年前无中央空调的 1.2 修正；
7. 饭店把 3级/2级/1级写成约束/基准/引导；
8. 饭店综合能耗漏掉新水 0.2571；
9. 饭店修正系数只列出租率、且当乘数；
10. 水耗把 m³/(床·年) 写成 m³/(p·a)，或不做入住率折算；
11. 人均指标分母用建筑面积；
12. 表内 tce 与 kgce 混用。

## 六、复算校验

1. 分子分母单位一致；
2. 电力系数 0.1229；饭店新水 0.2571；
3. 建筑面积与第2章表2.1 一致（饭店按 Mm 公式）；
4. 人数/床位与项目登记一致；
5. 指标值可由表内基础数据复算（误差 ≤ 0.01）；
6. 对标档位与数值匹配；
7. 736 主要/参考指标标注正确；
8. 760 3级/2级/1级标注正确；
9. 修正系数连乘方向正确；
10. 水耗单位与定额口径一致；
11. 不出现 DB37 标准号。
