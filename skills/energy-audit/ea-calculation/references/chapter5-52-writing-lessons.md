## 段2详细规范（本会话教学重点）

### 2.1 整体评价 —— 波动率阈值表

先计算所有年份的同比变化率，再按以下规则判定：

| 条件 | 描述文本 |
|------|---------|
| 所有变化率绝对值 < 5% | 整体波动不大 |
| 最大变化率绝对值 5%-15% | 整体呈小幅波动 |
| 最大变化率绝对值 > 15% | 整体波动较大 |
| 所有变化率 > 0（全增） | 整体呈上升趋势 / 逐年增长 / 逐年持续增长 |
| 所有变化率 < 0（全减） | 整体呈下降趋势 / 逐年递减 / 逐年持续下降 |
| 第一年增、最后一年减 | 先增加后减少，在一定范围内波动 |
| 第一年减、最后一年增 | 先减少后增加，在一定范围内波动 |

判定优先级：方向判定（全增/全减/先增后减/先减后增） > 幅度判定（波动不大/小幅/较大）

### 2.2 逐年增减量 + 增减率

对每一年（vs前一年），输出格式：
```
{当年}年{用能类型}较{上年}年{增加|降低}{绝对量}{单位}，{增加|降低}率为{百分比}%。
```

示例："2023年用电量较2022年增加135,500kWh，增加率为2.66%"

边界情况：
- 变化率绝对值 < 0.01% → "基本持平"
- 上年=0且本年>0 → "{当年}年新增{用能类型}{本年值}{单位}"
- 上年=0且本年=0 → "{当年}年与{上年}年均无{用能类型}"

### 2.3 异常标注

任何一年同比变化率绝对值 > 15% 时，在逐年描述后追加：
```
其中{年份}年{用能类型}变化幅度超过15%，属于异常波动，建议进一步核实该年度用能异常原因。
```

此项为标记，发现后应向用户询问异常原因，待用户回复后写入正文。

## 段4逐月分析因果链（v4.1 — 本会话教学重点）

旧版只有空洞的"夏季高于冬季"，新版必须结合被审计单位实际冷源/热源设备写因果链。

### 四步法

1. **识别高峰月** — 取跨年月均值，找出高于整体均值105%的月份
2. **制冷季因果链** — 从 buildings 取 cold_source → 判断是否电驱动 → 解释6-9月高耗原因
3. **供暖季因果链** — 从 buildings 取 heat_source → 即使主热源非电力，循环泵+分体空调补暖 → 解释12-1月高耗
4. **收口总结** — "供冷、供暖系统年用电量占总用电量比重较大，逐月用电量变化符合季节性用能变化规律"

### 示例输出（省立医院东院区）

```
由图5.1a分析，省立医院东院区用电量较大月份为1月、6月、7月、8月。

结合制冷空调形式分析，夏季空调冷源为水冷冷水机组、风冷冷水机组，
为电驱动式制冷机组，制冷动力消耗为电，受夏季制冷因素的影响，
6月、7月、8月单月用电量明显高于4月、5月、10月、11月无制冷需求
或需求较少的月份，单月用电量变化受季节性影响因素较大。

冬季以市政供暖、集中供暖为主，热源主要为供暖热水，热源形式虽不是
电力直接驱动，但换热站循环泵24h开启，同时部分房间使用分体空调
辅助供暖，因此供暖季（1月）用电量同样高于4月、5月、10月、11月
无供暖需求或需求较少的月份。

省立医院东院区供冷、供暖系统年用电量占总用电量的比重较大，
逐月用电量变化符合单位用能变化以及季节性用能变化规律。
```

## 段4月份同比异常检测（v4.1）

### 检测逻辑

对每种有逐月数据的能源类型，计算每个月份与上年同期的增减率：

```python
yoy_rate = (curr_val - prev_val) / prev_val * 100
if abs(yoy_rate) > 30:  # 标记为异常
```

### 输出格式

```

（同比变化率超过±30%）：{年份}年：{月份}（较上年同期{增长|降低}{rate}%，
由{prev}变为{curr}）...。建议进一步核实以上月份异常波动原因。
```

### 可解释异常（学校）

```python
if '教育' in institution_category:
```

### 注意事项

- 上期为0或null时跳过该月对比
- 增减量 = |本期 - 上年同期|
- 增减率 = 增减量 / 上年同期 × 100%，保留一位小数
- 增长用"增长"、"增加"；下降用"降低"、"减少"
- 仅对 electricity_kwh / water_m3 / natural_gas_m3 做同比检测（加热/用油无逐月数据）

## 5.2.6 能源资源费用分析（v4.3 — 本会话教学）

### 五段式结构

```
段1（开头）: 根据所提供的能耗账单及缴费发票，{单位名}能源费用主要包括
            {电费、燃气费、水费、供暖费、油费等}。
            {起始年}年-{结束年}年各项能源费用统计见表5.{section_num}。

表5.X  费用统计表（费用类型 × 各年（万元） + 合计行）

图5.X  各年能源费用占比饼状图（一年一张，仅含>0的费用项，5色调色板）

段2（三层分析）:
  第一层 - 整体费用变化评价: "{单位名}{起始年}年-{结束年}年能源费用整体变化不大/呈小幅波动/波动较大。"
  第二层 - 逐年费用增减: "{当年}年能源费用较{上年}年{增加|降低}X万元，{增加|降低}率为X%。"
  第三层 - 占比最高分析: "能源费用占比最高的为{费用名}，占该单位能源消费总额的X%以上，影响{单位名}能源费用的主要因素是{费用名}支出。"
```

### 三层分析详细规范（v4.3 新增 — 本会话教学重点）

#### 第一层：整体费用变化评价

计算各年总费用（所有费用类型求和），然后逐年计算同比增长率，按阈值判定：

| 最大变化率 | 描述 |
|-----------|------|
| < 5% | 整体变化不大 |
| 5%-15% | 整体呈小幅波动 |
| > 15% | 整体波动较大 |

#### 第二层：逐年费用增减

格式：`{当年}年能源费用较{上年}年{增加|降低}{绝对金额}万元，{增加|降低}率为{百分比}%。`

边界处理：
- 上年费用=0且本年>0 → `{当年}年新增能源费用{本年}万元`
- 变化率≈0 → `{当年}年能源费用与{上年}年基本持平`

#### 第三层：占比最高分析

取最新一年的费用数据：
- 如果最高项占比 ≥ 50% → `能源费用占比最高的为{top_name}，占该单位能源消费总额的{top_pct}%以上，影响{unit_name}能源费用的主要因素是{top_name}支出。`
- 如果前两项合计 > 50% → `能源费用占比最高的为{n1}（{p1}%）和{n2}（{p2}%），两项合计占能源消费总额的{p1+p2}%以上，是影响{unit_name}能源费用的主要支出类型。`

示例输出（省立医院东院区）：
```
省立医院东院区2022年-2024年能源费用整体变化不大。

2023年能源费用较2022年增加6.85万元，增加率为1.13%，
2024年能源费用较2023年降低14.86万元，降低率为2.43%。

能源费用占比最高的为电费，占该单位能源消费总额的63%以上，
影响省立医院东院区能源费用的主要因素是电费支出。
```
