# 第5.2节 能源资源消耗/消费数据 — 参考报告写作规范

## 来源

基于"日照市岚山区自然资源局"等省直能源审计报告的5.2实际写法提取。

## 每小节结构（以5.2.1 用电为例）

```
5.2.1 用电情况分析 (H3)

段1（一段式，不分多段）:
  {单位}主要用电设备为{设备列表}。根据能耗账单及缴费发票统计分析，
  {单位}2022年全年用电量为XXX kWh，2023年全年用电量为XXX kWh，
  2024年全年用电量为XXX kWh。2022年-2024年总用电量变化趋势如图5.1所示。

图5.1  2022年-2024年总用电量（单位：kWh）

段2（由图分析）:
  由图5.1分析，{单位}2022年-2024年总用电量{趋势描述}。
  其中2023年同比增长X%，2024年与上年基本持平。

图5.1a  逐月用电量趋势（单位：kWh）  ← 如果有月度数据

逐月分析:
  从逐月用电量来看，{季节性描述}，最高月份为X月（XXX kWh），最低月份为X月（XXX kWh）。
```

## 关键规则

1. **段1不分段**：三年具体数值全部放在一句话里。不要写成"2022年全年用电量为A，2023年全年用电量为B"各一句。
2. **趋势图引用在段1末尾**：在说完三年数值后立即说"变化趋势如图X所示"。
3. **段2用"由图X.X分析"开头**：不是"从逐年数据来看"、"综上所述"之类的。
4. **逐月分析格式**：夏季/冬季对比 + 最高最低月份 + 数值。
5. **设备描述按能源类型区分**：
   - 用电: "主要用电设备为XXX"
   - 用水: "用水系统主要为XXX"
   - 用气: "用气系统主要为XXX"
   - 供暖: "供暖采用XXX"

## 费用分析（5.2.N+1）

```
{单位}能源费用方面，电费三年平均XX万元，呈{趋势}；水费三年平均XX万元...
```

不需要表格——纯文字描述。

## Pitfalls

1. **设备描述不要说"主要用电设备"当写水或气时**——用`et_key`区分
2. **逐年分析和逐月分析分开写**——不要混在同一个段落
3. **逐月图用柱状图，不是折线图**
4. **逐月分析只写最近一年**——取 `monthly_data[-1]` 做分析
5. **"其中"用在逐年分析末尾**——作为补充细节的段落
