# 第5章：能源资源消费/消耗指标分析 v3.0

> 当前版本。v2.1旧版含表格——已废弃。

## 5.1 能源资源消费/消耗概况
- 一句话概述："{单位}主要用能类型包括X、Y、Z。"
- 图5.1 能源流向图（graphviz，按实际用能+设备动态生成）
- ❌ 不需要饼图、表格、逐年对比表

## 5.2 能源资源消耗/消费数据（无表，按类型动态H3）
每个小节结构：
  段1: 设备描述(按能源类型区分，水/气不能说"用电设备") + 逐年精确数值(一句) + 图引用
  图5.N 逐年柱状图
  段2: "由图5.N分析，{趋势}。" + 逐年增减量率 + 异常标注
  图5.Na 逐月柱状图(如有monthly_*数据)
  段3: "从逐月{XX量}来看，{季节性规律}。" + 最高/最低月份 + 异常波动(>±30%标注)

关键规则:
- ❌ 每个小节无表格
- ✅ 设备描述按能源类型区分
- ✅ 趋势分析"由图5.X分析"开头
- ✅ 月度分析含季节性判断+月份同比

## 5.3 能耗指标（5项，公式+表格+DB37对标；供暖项有供暖项目才生成）
表号动态: next_table = section_num + 1（5.2生成了section_num个能源类型小节）
指标表格式: 行列转换（转置）——首列为指标项（基础数据/指标值/对标值/评价），各统计年份为列

## 5.4 能耗基准（用量+费用）
表号动态: next_table+5, next_table+6

## 章节结构（基于日照市岚山区人民医院参考报告）

```
第5章 能源资源消费/消耗指标分析

  总述 — 审计周期 + 用能类型 + 数据来源概述

  5.1 能源资源消费/消耗概况
    - 一句话概述（"{单位}主要用能类型包括X、Y、Z。"）
    - 能源流向图（graphviz生成，三层结构，动态适配用能类型+设备清单）
    - ❌ 不需要饼图、不需要表格

  5.2 能源资源消耗/消费数据（H3按实际用能类型动态生成，无表格）
    格式：段1(设备描述+逐年精确数值+图X.X参考) → 柱状图 → 段2(由图分析趋势+同比变化)
    
    5.2.1 用电情况分析
      段1: "{单位}主要用电设备为{空调、照明、办公设备等}。根据能耗账单及缴费发票统计分析，
           {单位}2022年全年用电量为XXXkWh，2023年全年用电量为XXXkWh，
           2024年全年用电量为XXXkWh。2022年-2024年总用电量变化趋势如图5.1所示。"
      图5.1 柱状图（单位：kWh）
      段2: "由图5.1分析，{单位}2022年-2024年总用电量{趋势描述}。
           其中2023年同比增长X%，2024年...。"
    
    5.2.2 用水情况分析 → 同上，设备描述用"用水系统主要为..."
    5.2.3 用气情况分析 → 同上，设备描述用"用气系统主要为厨房炉灶设备用气"
    5.2.N+1 能源资源费用分析（最后一节固定，仅文字无表）
  
  关键规则:
  - 每个小节无表格（仅文字+柱状图），表号留给5.3/5.4
  - 设备描述必须按能源类型区分（不能说水/气小节"主要用电设备为..."）
  - 柱状图用 _generate_single_energy_chart() 生成
  - 趋势分析必须有"由图5.X分析"开头
  - 数值需展示精确值（含逗号千分位）

  5.3 能耗资源消耗/消费指标
    5.3.1 单位建筑面积非供暖能耗（公式+表格+DB37对标）
    5.3.2 常规用能系统单位建筑面积电耗
    5.3.3 人均综合能耗
    5.3.4 取水指标（用水指标；标题按机构类型自适应，映射见 core/references/standards-values.md）
    5.3.5 单位采暖建筑面积供暖能耗（有供暖能耗的项目必写；无供暖跳过）

  5.4 建筑能耗基准
    5.4.1 能源资源用量基准（三年平均值）
    5.4.2 能源资源费用基准（三年平均值）
```

## 数据来源

| 数据类型 | 优先来源 | 备选 |
|----------|----------|------|
| 能耗数据 | ts_institution_energy_main/data (data_type=1) | ts_energy_data |
| 费用数据 | ts_institution_energy_main (data_type=2) | 用户Excel手动输入 |
| 供冷/供热/交通能耗 | ts_institution_energy_main (data_type=3/4/5) | 用户提供 |
| 折标系数 | ts_energy_standard → 内置默认(GB/T 2589) | 用户提供 |
| 定额对标值 | DB37/T 2673-2019 医疗机构标准 | web_search |
