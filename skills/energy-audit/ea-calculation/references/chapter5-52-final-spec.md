# 第5.2节写作规范（最终版）

## 原则

- **不生成数据表**：5.2小节只含分析文字 + 图表，不用表格展示数据
- **分析文字在图表前**：先写总趋势分析，再放图
- **逐年图后有分析**：逐年柱状图后紧跟"由图分析"段落
- **逐月图后有分析**：逐月柱状图后紧跟季节性分析和异常检测

## 每小节结构

```
5.2.N  XX情况分析

  段1（图前）: 设备描述 + 各年具体数值 + "变化趋势如图5.N所示"
    ex: "莘县政府主要用电设备为中央空调、柜机、挂机等。
         根据能耗账单及缴费发票统计分析，莘县政府2022年全年用电量为495,180kWh，
         2023年全年用电量为521,531kWh，2024年全年用电量为517,452kWh。
         2022年-2024年总用电量变化趋势如图5.1所示。"

  图5.N: 逐年柱状图

  段2（逐年分析）: "由图5.N分析，XX年-XX年总XX量XXX趋势。"
    + 逐年变化量/率（"2023年同比增加X%，2024年同比降低Y%"）
    + 异常标注（变化幅度>15%时提示核查）

  图5.N+1: 逐月分组柱状图（如有月度数据；独立编号全章连号，
           图注"Y1年-Y3年逐月XX量（单位：XX）"；无月度数据不画图）

  段3（逐月分析）: "从逐月XX量来看，夏季明显高于冬季（或反之），
    最高月份为X月，最低月份为Y月。"
    + 季节性规律分析
    + 年际异常月份标注（同比变化>±30%）
    + 原因推断（制冷/供暖季影响）
```

## 设备描述按能源类型区分

```python
if et_key == 'electricity_kwh':
    eq_str = "主要用电设备为中央空调、柜机、挂机等"
elif et_key == 'water_m3':
    eq_str = "用水系统主要为生活用水、卫生清洁用水等"
elif et_key == 'natural_gas_m3':
    eq_str = "用气系统主要为厨房炉灶设备用气"
elif et_key == 'heating_energy_heat_gj':
    eq_str = "供暖采用市政集中供热，末端为散热器采暖"
```

## 季节性判定

```python
summer = latest[5:9]  # 6-9月
winter = latest[11:] + latest[:2]  # 12-2月
if summer_avg > winter_avg * 1.2: "夏季明显高于冬季"
elif winter_avg > summer_avg * 1.2: "冬季明显高于夏季"
else: "各月用量分布较为均匀"
```

## 异常检测阈值

- 年度同比变化 > ±15% → 标注"异常波动，建议核查"
- 月度同比变化 > ±30% → 列出具体月份和数值变化

## Pitfalls

1. **不能所有小节都写"主要用电设备"** — 用水/用气/用暖必须区分
2. **表和图不要同时出现** — 用户明确要求5.2不要数据表
3. **先分析再放图** — 不是先放图再分析
