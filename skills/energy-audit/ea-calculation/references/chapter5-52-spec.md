# 5.2 编制规范 v3.4 — 参考报告三段式

> **来源**: 日照市岚山区自然资源局/财政局、省人社厅实际报告
> **核心**: 段1(设备+具体数据+图引用) → 图(逐年总量柱+逐月分组柱) → 段2(由图分析+同比细节)

## 每小节结构

```
5.2.N  XX情况分析

  段1: [单位]{设备描述}。根据能耗账单及缴费发票统计分析，
       [单位]2022年全年用电量为XXX kWh，2023年全年用电量为XXX kWh，
       2024年全年用电量为XXX kWh。2022年-2024年总用电量变化趋势
       如图5.N所示。

  图5.N   2022年-2024年总用电量（单位：kWh）（逐年柱状图）
  图5.N+1 2022年-2024年逐月用电量（单位：kWh）（逐月分组柱状图）
          [有月度数据时嵌入，无月度数据不画图（如市政供暖热力）]

  段2: 由图5.N分析，[单位]2022年-2024年总用电量整体波动不大，
       基本保持平稳。其中2023年同比增长X.X%，2024年同比下降X.X%。
```

## 关键规则

1. **段1 "一句话全含"**: 设备数字 + 三年具体数值 + 图引用
2. **设备描述按能源类型区分**: 用电→"主要用电设备为XXX等"，用水→"用水系统主要为XXX"，用气→"用气系统主要为XXX"
3. **图标题**: "图5.N  X年-X年总XX量（单位：XX）"
4. **段2 "由图分析"**: 必须有"由图5.N分析"开头
5. **同比合并**: "其中2023年同比...，2024年同比..."一段，不逐句
6. **趋势词**: +5%→"呈逐年增长"；-5%→"呈逐年下降"；其他→"整体波动不大，基本保持平稳"
7. **不含表格** 🚫: 整个5.2无表格，数值在正文呈现（费用节除外，见表5.1）
8. **逐月分组柱状图**: 图5.N+1（独立编号、全章连号），有月度数据时嵌入，
   图注"Y1年-Y3年逐月XX量（单位：XX）"
9. **画图范围**: 仅"有月度抄表数据的主要能源类型"画总量+逐月图；
   主要能源=折标能耗占比≥5%或水，其余并入"其他用能分析"（纯文字小节）

## 月度数据支持

Config中 `energy_yearly` 每个条目可带可选月度字段:
```json
{
  "year": 2023,
  "electricity_kwh": 521531,
  "monthly_electricity_kwh": [46884,38688,36444,...],  // 12个值，1-12月
  "monthly_water_m3": [263,181,297,...]
}
```

EnergyYearly dataclass: `monthly_electricity_kwh: Optional[List[float]] = None`
load_from_project 自动传递到 energy_data_list。
