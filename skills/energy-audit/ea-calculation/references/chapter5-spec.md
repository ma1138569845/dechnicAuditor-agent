## 结构规范（原 chapter5-52-final-spec，5.2 结构权威单点）

> ★【结构权威单点 2026-09-05】5.2 节结构（分节/图表/段序）以本节为准；行文细节（三级逻辑/异常标注句式）见本文件《5.2 写作教训与踩坑细节》一节。原 5.2 相关文件已归档（`_archive/2026-09-18/`）。

### 原则

- **不生成数据表**：5.2小节只含分析文字 + 图表，不用表格展示数据
- **分析文字在图表前**：先写总趋势分析，再放图
- **逐年图后有分析**：逐年柱状图后紧跟"由图分析"段落
- **逐月图后有分析**：逐月柱状图后紧跟季节性分析和异常检测

### 每小节结构

```
5.2.N  XX情况分析

  段1（图前）: 设备描述 + 各年具体数值 + "变化趋势如图5.N所示"
    ex: "莘县政府主要用电设备为中央空调、柜机、挂机等。
         根据能耗账单及缴费发票统计分析，莘县政府2022年全年用电量为495,180kWh，
         2023年全年用电量为521,531kWh，2024年全年用电量为517,452kWh。
         2022年-2024年总用电量变化趋势如图5.1所示。"

  图5.N: 逐年柱状图

  段2（逐年分析）: "由图5.N分析，XX年-XX年总XX量XXX趋势。"
    + 逐年变化量/率（"2023年同比增加X%，2024年同比降低Y%"）
    + 异常标注（变化幅度>15%时提示核查）

  图5.N+1: 逐月分组柱状图（如有月度数据；独立编号全章连号，
           图注"Y1年-Y3年逐月XX量（单位：XX）"；无月度数据不画图）

  段3（逐月分析）: "从逐月XX量来看，夏季明显高于冬季（或反之），
    最高月份为X月，最低月份为Y月。"
    + 季节性规律分析
    + 年际异常月份标注（同比变化>±30%）
    + 原因推断（制冷/供暖季影响）
```

### 设备描述按能源类型区分

```python
if et_key == 'electricity_kwh':
    eq_str = "主要用电设备为中央空调、柜机、挂机等"
elif et_key == 'water_m3':
    eq_str = "用水系统主要为生活用水、卫生清洁用水等"
elif et_key == 'natural_gas_m3':
    eq_str = "用气系统主要为厨房炉灶设备用气"
elif et_key == 'heating_energy_heat_gj':
    eq_str = "供暖采用市政集中供热，末端为散热器采暖"
```

### 季节性判定

```python
summer = latest[5:9]  # 6-9月
winter = latest[11:] + latest[:2]  # 12-2月
if summer_avg > winter_avg * 1.2: "夏季明显高于冬季"
elif winter_avg > summer_avg * 1.2: "冬季明显高于夏季"
else: "各月用量分布较为均匀"
```

### 异常检测阈值

- 年度同比变化 > ±15% → 标注"异常波动，建议核查"
- 月度同比变化 > ±30% → 列出具体月份和数值变化

### Pitfalls

1. **不能所有小节都写"主要用电设备"** — 用水/用气/用暖必须区分
2. **表和图不要同时出现** — 用户明确要求5.2不要数据表
3. **先分析再放图** — 不是先放图再分析

### 5.3 能耗资源消耗/消费指标（每个指标同构五要素）

> 3. 人均综合能耗（5.3.3）

### 三档评价规则（对标 energy-audit-core/references/standards-values.md（权威单点））

| 指标值区间 | 评价结果 | 结论句式 |
|-----------|---------|---------|
| ≤ 引导值 | 优于引导值 | 用能水平先进 |
| 引导值＜值≤基准值 | 低于基准值 | 高于引导值，仍然存在一定的节能空间 |
| 基准值＜值≤约束值 | 低于约束值 | 高于基准值，仍然存在较大的节能空间 |
| ＞约束值 | 超出约束值 | 不满足定额约束要求（须重点说明原因并加大整改建议力度） |

> 用水指标两档：先进值/通用值，句式"低于通用值，高于先进值，仍然存在一定的节水空间"。

### 计算规则

1. **综合能耗**（tce）= Σ(各类计入能源实物量 × 折标系数)。计入范围：机构自缴的电/热/油/气；第三方托管结算的能源（如物业代缴燃气）是否计入须与用户确认并在 5.3.3 注明口径。
2. **折标系数**：见 energy-audit-core/references/standards-values.md（权威单点）（电力 0.31 kgce/kWh 等价、热力 0.03412 tce/GJ（换算 34.12 kgce/GJ，代码 COEFF.heat 直乘勿再 ÷1000）、汽油 1.4714 kgce/kg、天然气 1.2143 kgce/m³）。**水不折算标准煤，不计入综合能耗**（附录B 无水的折标系数）。
3. **单位采暖建筑面积供暖能耗**（5.3.5）= 供暖能耗 kgce ÷ 采暖建筑面积。供暖能耗 = 供暖电耗×0.31 + 供热量(GJ)×34.12 + 供暖燃气×1.2143；采暖建筑面积取建筑表 heat_area 合计，缺失时用建筑面积兜底（用户 2026-09-02 确认）。定额按供暖类型（表2，不分机构等级）：市政集中供暖(按热计量) 12.7/11.1/8.3；空调供暖 12.4/8.9/6.4；燃气(油)供暖 12.3/8.4/4.8。预计算指标见 data.json indicators[].unit_area_heating。
3. **同比增减量** = 后年值 − 前年值；**增减率** = 增减量 ÷ 前年值 × 100%，保留 2 位小数。
4. **数值精度**：账单原始数据保留 2 位小数；指标值保留 2 位小数；费用以万元计保留 2 位。
5. **信息中心用电跨年处理**：仅有一个年份的单独计量数据时，取该值作为近三年平均值填入三个年份（须在正文说明该假设）。

#### 供暖电耗剔除（⚠️ 计算口径铁律，缺失将整体偏高约15%）

单位建筑面积**非供暖能耗**与**常规用能系统单位建筑面积电耗**，计算前必须从总电量中**扣除供暖系统耗电量**（供暖循环泵、供暖风机等电耗；含市政供暖项目的循环泵电耗）：

- 表5.2 计算：非供暖能耗 = 综合能耗 − 供暖能耗（热+供暖电耗）− 交通能耗（汽油+柴油），再 ÷ 建筑面积。**不得只用总电量折标**（旧只电口径已废弃 2026-09-05）。
- 表5.3 计算：单位面积电耗 =（年耗电量 − 供暖耗电量）÷ 建筑面积；不得用总电量直接除以面积。
- 供暖耗电量单独计量缺失时：由用户提供（循环泵功率×运行时长等）或按供暖期循环泵测算，禁止用 0 代入。
- 预计算指标（data.json indicators）的 heating_energy_kwh 缺失时按 0 计入，属"未剔除口径"，
  写 5.3 章节时不得直接引用该预计算值，须按本条铁律修正后写入。
- 历史事故：某项目未剔除供暖电耗（159,682.5/120,075/78,210 kWh），非供暖能耗 14.38 vs 正确 12.34 kgce/(m²·a)，评价结论偏差一档。

#### 建筑面积分母口径（D8）

计算 5.3.1 单位建筑面积非供暖能耗、5.3.2 常规用能系统单位建筑面积电耗的分母时，按定额标准建筑面积统计口径**剔除地下车库面积**（分母 = 建筑面积 − garage_area）。采暖建筑面积不受影响（5.3.5 取 heat_area 合计）。示例：法院 24,300 − 2,000 = 22,300 m²。依据：DB37 定额标准"车库面积不计入建筑面积统计"＋避坑规则 D8。

#### 口径统一（⚠️ 全章同一口径，禁止混用）

- 5.1 概况**不列综合能耗数值**（只给流向图与用能类型）；综合能耗数值只在 5.3.3 给出。
- 5.3 全章统一**等价值**口径（电力 0.31 kgce/kWh）；禁止 5.1 用当量（0.1229）而 5.3.3 用等价、或电当量+气等价混算。
- 若项目合同约定当量口径，须在 5.3 注明"按合同约定当量口径"并全章一致。

#### 数据交叉校验（写入正文前必做）

1. **年度总量 = 逐月加总**：三年 × 每种能源，逐月值加总须与年度总量一致（偏差>0.5% 时以账单原件为准并标注）。
2. **费用 ÷ 单价 = 用量**：如供暖 320,355.75 元 ÷ 89.61 元/GJ = 3,575 GJ；电费 ÷ 电量 ≈ 当地电价。校验失败的数据禁止直接写入报告。
3. **版本冲突校验**：PG 取数如出现同键多版本不同值，以账单原件/交付报告互证为准，标注"DB 数据与账单不符，已按账单修正"。

### 段2详细规范（本会话教学重点）

#### 2.1 整体评价 —— 波动率阈值表

先计算所有年份的同比变化率，再按以下规则判定：

| 条件 | 描述文本 |
|------|---------|
| 所有变化率绝对值 < 5% | 整体波动不大 |
| 最大变化率绝对值 5%-15% | 整体呈小幅波动 |
| 最大变化率绝对值 > 15% | 整体波动较大 |
| 所有变化率 > 0（全增） | 整体呈上升趋势 / 逐年增长 / 逐年持续增长 |
| 所有变化率 < 0（全减） | 整体呈下降趋势 / 逐年递减 / 逐年持续下降 |
| 第一年增、最后一年减 | 先增加后减少，在一定范围内波动 |
| 第一年减、最后一年增 | 先减少后增加，在一定范围内波动 |

判定优先级：方向判定（全增/全减/先增后减/先减后增） > 幅度判定（波动不大/小幅/较大）

#### 2.2 逐年增减量 + 增减率

对每一年（vs前一年），输出格式：
```
{当年}年{用能类型}较{上年}年{增加|降低}{绝对量}{单位}，{增加|降低}率为{百分比}%。
```

示例："2023年用电量较2022年增加135,500kWh，增加率为2.66%"

边界情况：
- 变化率绝对值 < 0.01% → "基本持平"
- 上年=0且本年>0 → "{当年}年新增{用能类型}{本年值}{单位}"
- 上年=0且本年=0 → "{当年}年与{上年}年均无{用能类型}"

#### 2.3 异常标注

任何一年同比变化率绝对值 > 15% 时，在逐年描述后追加：
```
其中{年份}年{用能类型}变化幅度超过15%，属于异常波动，建议进一步核实该年度用能异常原因。
```

此项为标记，发现后应向用户询问异常原因，待用户回复后写入正文。
